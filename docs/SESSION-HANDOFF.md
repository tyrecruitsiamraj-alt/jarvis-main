### 3. ฟอร์ม HTML ยิง submit เองได้ 3 ทาง — ต้องปิดทั้งสามถึงจะพอ

หน้า Follow โดนบันทึกเองซ้ำ **3 รอบ** กว่าจะปิดครบ:
1. **implicit submit** — Enter ในช่องใด ๆ (แก้: ด่าน `step !== 3` ห้ามบันทึก)
2. **Enter ที่ตกไปถึงฟอร์ม** (แก้: `onSubmit={preventDefault}` ฟอร์มไม่รับ submit เลย
   บันทึกผูกกับ `onClick` ของปุ่มที่เดียว)
3. 🔴 **คลิกซ้อนตำแหน่งปุ่ม** — กด "ถัดไป" แล้วปุ่ม "บันทึก" มาเรนเดอร์บริเวณเดิมทันที
   คลิกที่สองของคนกดเร็วตกบนบันทึกพอดี (ทับกันหรือไม่ขึ้นกับความสูงจอ — เครื่องเราไม่ทับ

* 🔴 **จับเวลาเข้าขั้นต้องทำตอนคลิก (`goToStep`) ไม่ใช่ใน `useEffect`** — effect วิ่งหลัง paint
  คลิกซ้อนที่เร็วกว่าเฟรมแรกเห็น ref เป็นค่าเก่า ด่านไม่ทำงาน

### กับดักตอน "ตรวจงาน" (สะสม)

- **console log ค้างในบัฟเฟอร์** — ดู error สดต้อง**เปิดแท็บใหม่**
- **screenshot ดำ/เพี้ยนบ่อยมากในเซสชันนี้ — ให้วัดจาก DOM แทน**
  (`getBoundingClientRect` / `getComputedStyle`) เชื่อถือได้กว่ามาก
- **`javascript_tool` ใช้ ES5 syntax ให้ปลอดภัย** — arrow function + `const` ใน object literal
  เคยพัง `SyntaxError` · ใช้ `[].slice.call()` แทน spread
- **viewport ของแท็บใหม่เป็น 0×0** ต้อง `resize_window` ก่อนวัดเสมอ ไม่งั้นได้เลขมั่ว (38px)
- **responsive ตรวจที่ 320 · 375 · 414 · 768 · 1023 · 1440**
- สลับธีมทดสอบใช้ `localStorage['jarvis:theme']` แล้ว reload
- **grid: ช่อง `auto` ที่ไม่มีลูกจะยุบเหลือ 0** แล้วโยนความกว้างไปให้ช่อง `1fr` —
  ต้องใส่ div เปล่าคั่นไว้ ไม่งั้นคอลัมน์สองแถวไม่ตรงกัน

## 6. สไตล์ที่เจ้าของชอบ (สำคัญ — ทำตามนี้)

- สั่งเป็น bullet ไทยสั้น ๆ ทีละหลายข้อ → **ทำครบทุกข้อแล้วสรุปทีเดียว**
- **มักส่ง DOM ของ element มาชี้จุด** แทนการอธิบาย — อ่าน class/ข้อความในนั้นเพื่อหาไฟล์
- **ตรวจงานเองในเบราว์เซอร์เสมอ** อย่าให้เจ้าของไปกดเอง รายงานสิ่งที่**วัดได้จริง**
- **commit & push ทีละข้อ** ไม่ต้องรอถาม · commit message ไทย ยาวได้
  บอก**เหตุผล**และ**สิ่งที่ตรวจจริง**
- เอาฟีเจอร์ออก = เอาออกให้สุด (UI + state + import ที่ตายตาม + เทสต์ที่อ้างไฟล์ที่ลบ)
  **แต่ถ้ามีของค้างที่ต้องมีที่ไป ให้ย้ายไม่ใช่ลบ** — และถ้าไม่มีที่ไปแล้วจริง ๆ **ต้องบอก**
- เจ้าของทักเรื่องตัวเลข = เช็คฐานจริงก่อนเสมอ มักเป็น "เลขถูกแต่ตอบผิดคำถาม"
- เขียนเทสต์แล้ว **mutation test** — จงใจแก้โค้ดให้พัง ดูว่าเทสต์ล้มตรงจุด แล้วคืนไฟล์
- **รายงานตรง ๆ** — อะไรตรวจแล้ว อะไรยังไม่ได้ตรวจ ต้องบอก อย่ากลบ
- ตอบภาษาไทย
