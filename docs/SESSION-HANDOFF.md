## 2. งานที่เสร็จรอบนี้ (8–10 ส.ค. · commit `65f6c87` → `bc43dca`)

**UI/UX ตามที่เจ้าของติง (ทำครบ ตรวจในเบราว์เซอร์ทุกข้อ)**
- แก้ burger ซ้อนกระดิ่งบนมือถือ (หัวจอเล็กเกิน 438px = พังทุกรุ่น) + `PageHeader`
  ล้นจอ 320px — ย้าย "เปลี่ยนรหัสผ่าน/ออกจากระบบ" เข้าเมนูข้าง
- funnel หน้าหลักแบ่ง **2 บรรทัด**: เส้นหลัก (เปิดอยู่ → AI แนะนำ → ส่งโทร →
  **ผลจากการโทร** → จอง/ลงงาน) · บรรทัดล่าง "ยังไม่มีคน → Content/Scraping"
- "ผลจากการโทร" สีตามความหมาย: สนใจ=เขียว · ไม่สนใจ=แดง · ไม่รับ=เหลือง ·
  ถอดป้าย "เดือนนี้" ที่โกหกครึ่งนึง · การ์ด funnel ขยาย **125%** (เลข 33.75px)
- "การไหลของการโทร" ย้ายจากหน้าหลักไปหน้า Follow เป็นกล่อง hero + **ปุ่มสลับต้นทาง**
  (เริ่มที่ "จากหน้านี้") — แก้เรื่อง "ส่ง 1 คนทำไมขึ้น 5,307" (5,307 = card 5,280 +
  ir 26 + follow 1 · API รับ `?source=`)
- รวมโทนสีผลโทรเป็นแหล่งเดียว `CALL_OUTCOME_TONE` (เดิม 4 ไฟล์ประกาศเอง ไม่ตรงกัน)
- หน้า Matching: การ์ดสรุปเป็นหน่วย **อัตรา** ("อัตราทั้งหมด" · ใบขอเป็นบรรทัดย่อย) +
  **สมการ 3 ถังลงตัวเสมอ** (เขียว+เหลือง+ยังไม่มีคน = ทั้งหมด — เดิมใบที่ AI
  ยังไม่ประเมินตกหล่น) + ปุ่ม **โยนกลับ** จากหน้าจองตัว
- แผงอนุมัติชุดส่งย้ายจากหน้า Follow → หน้างานโทร (เจ้าของสั่ง "Follow ไม่ต้องมีอนุมัติ")

**ฟีเจอร์**
- **นโยบายการโทร** (migration 073): ตั้งจากหน้า Follow ได้ว่าโทรต่อคนกี่ครั้ง /
  โทรได้ช่วงกี่โมง · PUT admin เท่านั้น + audit · ปิดช่องของใหม่โทรกลางคืน
  (`insertQueueItems` ตั้ง `next_attempt_at` พ้นช่วงห้าม)
- **ธงเตือนบนหน้าจองตัว** "เพิ่งมีผลโทรว่าไม่สนใจ" — รวม 2 แหล่ง (คน+AI) คีย์ด้วย
  เบอร์ E.164 · โชว์เฉพาะผลที่ใหม่กว่าการจองล่าสุด · ไม่ถอนจองอัตโนมัติ (fail-safe)

**ความปลอดภัย/คุณภาพ**
- SSO: รัดด่านกัน open redirect (`sanitizeReturnPath` กัน `\` + อักขระควบคุม) + เทสต์ 20 เคส
- ครอบ withAuth ให้ `/api/matching/worker-status` (ตัวเดียวที่เปิดโล่ง)
- **เปิด typecheck ให้ `api/` ครั้งแรก** (`tsconfig.api.json`) — พบว่าเดิมไม่มี config
  ไหนครอบเลย · แก้บั๊กจริง 3 กลุ่ม: เส้นปล่อยชุดโทรเรียกชื่อคนผิดทุกราย ·
  `logError` กลืน error+context (5 จุด) · `.replace` arg เกิน

## 3. ⚠️ กติกาที่ห้ามพลาด (เจ็บมาแล้วทั้งนั้น)

1. **DB local = production** — ทดสอบอะไรที่เขียนต้องคืนค่าเดิม
2. **เช็ก tsc สาม config — ต้องเป็น 0 ทั้งสาม** — สองตัวเดิม**ไม่มีตัวไหนครอบ `api/`**
   (default = references เปล่า · app = src เท่านั้น) ตัวที่สาม `tsconfig.api.json`
   ครอบ api · กวาดครบแล้ว 10 ส.ค. — error โผล่เมื่อไหร่ = ของใหม่พัง
3. **ห้ามแก้ class หลายจุดด้วย regex** — แก้มือทีละจุด หรือสคริปต์ "เติมท้ายอย่างเดียว"
4. **สีมาจาก `designTokens.ts` ที่เดียว** — กับดักบ่อยสุด: ใส่ `dark:border`/`dark:text`
   ครบแต่**ลืม `dark:bg`** · โทนผลโทรใช้ `CALL_OUTCOME_TONE` แหล่งเดียว
5. **ล็อกโทรผูกกับเบอร์ E.164 ไม่ใช่ `candidate_ref`** — คนเดียวมีหลายรหัส
6. **DB ตัดสินการชน ไม่ใช่ลำดับโค้ด** — partial unique index + อ่าน unique violation
7. **`insertQueueItems()` เป็นคอขวดเดียวของการเข้าคิวทุกเส้น** — ล็อก/พักเบอร์/
   ช่วงเวลาโทร กรองที่นั่นที่เดียว
8. **fail-safe ไปทาง manual/ไม่ส่งเสมอ** — เผลอโทรคนที่เลิกหางานแล้ว กู้ไม่ได้
9. **ช่วงห้ามโทรตั้งได้แล้ว** (นโยบายการโทร หน้า Follow) — default 20:00–08:00 ·
   คุมทั้งคิวใหม่และโทรซ้ำ
10. **`new Intl.*` ประกาศระดับโมดูลเสมอ** — รวม `toLocaleString()` ด้วย (18.7 เท่า)
11. **แจ้งเตือนต้องกลืน error เสมอ** — ฝั่งอ่านกลืนเฉพาะ 42P01 ที่เหลือโยนต่อ
12. **dev server ใช้ `preview_start`** (vite 8080 · api 3100) ห้ามรันด้วย Bash
    auth: `POST /api/auth/dev-role {"role":"admin"}` (cookie ~30 นาที หมดบ่อย)
13. **`verify-api-registry.mjs` รันด้วย `npx tsx` ไม่ใช่ `node`**

## 6. สไตล์ที่เจ้าของชอบ (สำคัญ — ทำตามนี้)

- สั่งเป็น bullet ไทยสั้น ๆ ทีละหลายข้อ → **ทำครบทุกข้อแล้วสรุปทีเดียว**
- **ตรวจงานเองในเบราว์เซอร์เสมอ** อย่าให้เจ้าของไปกดเอง รายงานสิ่งที่วัดได้จริง
- **commit & push ทีละข้อ** — ทำเสร็จข้อหนึ่ง push แล้วทำข้อถัดไปเลย ไม่ต้องรอถาม
- commit message ไทย ยาวได้ บอก**เหตุผล**และ**สิ่งที่ตรวจจริง**
- เอาฟีเจอร์ออก = เอาออกให้สุด (UI + state + URL param) แต่**ถ้ามีของค้างที่ต้องมี
  ที่ไป ให้ย้ายไม่ใช่ลบ** (เคสแผงอนุมัติ → หน้างานโทร)
- เจ้าของทักเรื่องตัวเลข = เช็คฐานจริงก่อนเสมอ มักเป็น "เลขถูกแต่ตอบผิดคำถาม"
  (เคส 5,307 vs 1) หรือ "สมการไม่ลงตัว" (เคส 3 ถัง Matching)
- เขียนเทสต์แล้ว **mutation test** — จงใจแก้โค้ดให้พัง ดูว่าเทสต์ล้มตรงจุด แล้วคืนไฟล์
- **รายงานตรง ๆ** — อะไรตรวจแล้ว อะไรยังไม่ได้ตรวจ ต้องบอก อย่ากลบ
- ตอบภาษาไทย
