### ✅ บล็อก 2 — คิวค้าง 140 คน — **เคลียร์แล้ว 13 ส.ค. 2569**

เจ้าของเคาะ: **ล้างทั้งหมด เริ่มใหม่** — ทำแล้วด้วย
`npx tsx scripts/cancel-stale-lumos-queue.mts --apply`

| วัดจากฐานจริง | ก่อน | หลัง |
|---|---|---|
| แถวค้างไม่มีผลกลับ | 4,849 (pending 2,481 + delivered 2,368) | **0** |
| คนที่จะถูกโทร | 140 | **0** |
| แถวในคิวทั้งหมด | 5,307 | **5,307** (ไม่ลบแถว แค่ `status = 'cancelled'`) |
| แถวที่มีผลโทรจริง | 49 | **49** (ไม่ถูกแตะ — ตรวจแล้วยอดทุก outcome เท่าเดิม) |
| ตัวเลขบนแผงหน้าหลัก | ค้างเกิน 2 วัน 4,849 | `waiting_call` / `delivered_waiting` / `stale_delivered` / `stale_pending` / `retry_scheduled` / `needs_human` = **0 ทั้งหมด** |

→ **เกณฑ์ Go/No-Go ข้อ 2 ผ่านแล้ว**

⚠️ **สองข้อที่ต้องรู้:**
1. **ยกเลิกฝั่งเราไม่ได้เรียกสายคืนจาก Lumos** — 2,368 แถวที่เขารับไปแล้วอยู่ในระบบเขา
   ถ้าเขากลับมาเดินคิวเก่า สายยังออกได้ · ฝั่งเราแค่จะไม่เสิร์ฟซ้ำ
   (`SERVE_ELIGIBLE` ไม่รับ `status = 'cancelled'`) และผลที่กลับมาจะไม่ถูกนับเป็นงานค้าง
   → **ควรบอกทีม Lumos ให้ล้างฝั่งเขาด้วย** ตอนคุยเรื่องบล็อก 1
2. ไฟล์สำรอง `lumos-queue-cancel-backup-16592.json` (4,849 แถว) อยู่ที่ root ของ repo
   **ไม่ขึ้น git** (มี person_ref ของผู้สมัครจริง) — ย้อนกลับได้จากไฟล์นี้

### บล็อก 3 — server จริงยังไม่ได้ตั้งค่า/รัน migration

- [ ] รัน migration ให้ถึง **082** บน server จริง (080 · 081 · 082 เป็นของรอบนี้)

## 🧪 หมุดที่ 2 — PoC Contents / Scrap (พฤหัส 20 ส.ค.)

### ของที่พร้อมแล้ว
- ปุ่มส่งคำขอจากหน้า Matching ครบทั้ง 2 ทาง (ส่งได้ทั้ง Content และ Scraping
  ในใบเดียวกันแล้ว ตั้งแต่ migration 080)
- หน้าติดตามคำขอ (`/matching/job-postings`) + สถานะ รอดำเนินการ → กำลังทำ → โพสแล้ว
- การ์ดบนหน้าหลักนับให้แล้ว ("ส่งคิด Content" / "ส่ง Scraping")
- **ของจริงบนฐานตอนนี้: คำขอ Content 3 ใบ** (รอดำเนินการ 2 · กำลังทำ 1) · Scraping 0 ใบ

### ที่ยังไม่มี — และเป็นเนื้อของ PoC
1. **ยังไม่มีใครรับงานไปทำจริงแล้ววัดผล** — ระบบส่งคำขอได้ แต่ยังไม่เคยเดินครบวง
   จนถึง "โพสแล้ว → มีคนสมัครเข้ามาจากโพสนั้น"
2. **ยังไม่รู้ว่าโพสหนึ่งครั้งได้คนกี่คน** — ต้องผูกใบสมัครกลับไปที่คำขอให้ได้
   (มี `posting_id` + ลิงก์สั้นเก็บช่องทางอยู่แล้ว — ยังไม่มีหน้าสรุป)

### ขอบเขต PoC ที่เสนอ (เจ้าของเคาะได้)
เลือกใบขอที่หาคนไม่ได้จริง **5 ใบ** → ส่ง Content 3 ใบ / Scraping 2 ใบ →
ทีมคอนเทนต์โพสจริง → วัด 7 วัน

**วัด 4 ตัว:** คำขอถึงมือทีมกี่ชั่วโมง · โพสจริงกี่ใบ · ใบสมัครที่เข้ามาจากโพสนั้นกี่ใบ ·
ในนั้นโทรแล้วสนใจกี่คน

### งานที่ต้องทำก่อน 20 ส.ค.
- [ ] **หน้าสรุปผลต่อคำขอ** — คำขอนี้โพสไปแล้วได้ใบสมัครกี่ใบ (ผูกด้วย `posting_id`)
      ⏱️ ประมาณครึ่งวัน · ไม่มีก็ทำ PoC ได้แต่ต้องนับมือ
- [ ] ตกลงกับทีมคอนเทนต์ว่าใครรับงาน + รับที่ไหน (ตอนนี้คำขอ 3 ใบค้างอยู่
      ยังไม่มีใครเปิดดู — ต้องมีคนรับผิดชอบก่อน ไม่งั้น PoC จะค้างตั้งแต่ขั้นแรก)
- [ ] เคาะว่า "Scrap" หมายถึงอะไรให้ตรงกัน (ดูดประกาศจากที่อื่นมาลงบอร์ดเรา?
      หรือดูดรายชื่อผู้สมัครจากแหล่งอื่น?) — คำนี้ยังไม่เคยนิยามในระบบ
