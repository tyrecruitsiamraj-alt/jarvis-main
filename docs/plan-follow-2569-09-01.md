# แผนรื้อหน้าติดตาม — เคาะแล้ว 1 ก.ย. 2569

> ⚠️ อยู่คนละคิวกับแผนกล่องงาน (`plan-board-2569-08-31.md`) ที่ก้อน B/C ยังค้างอยู่

## Concept ที่เจ้าของสั่ง (ยกมาตรง ๆ)

> 1. เปิดมาปุ๊บ เจอเป็น 3 หลัก ๆ เลย
>    1. calendar เผื่อต้องการดูแค่วันนั้นวันเดียว
>    2. ปุ่ม เพิ่มคนที่ต้องการติดตาม
>    3. เป็นเหมือน Planning เพื่อบอกว่ามีใครบ้าง และติดตามวันไหนบ้าง และใน Planning
>       ก็มีบอกว่าติดตามกี่รอบด้วย และเวลาไหนบ้าง
> 2. ปุ่มเพิ่มคน กดแล้วเด้ง Popup พาทำทีละขั้น: ① ค้นหาชื่อ → ② หน่วยงาน →
>    ③ วันเวลา กี่รอบ ชื่อ+เบอร์เจ้าหน้าที่ให้โทรกลับ **และบอกว่ารอบไหนใช้บทไหน**
> 3. Visual Control บนสุด — แต่ละวันต้องโทรกี่สาย ผลลัพธ์ยังไง **กดแล้วเด้ง Popup**

## ของเดิมที่มีอยู่แล้ว — ต่อยอด ไม่ต้องสร้างใหม่

| ของ | สภาพตอนนี้ |
|---|---|
| ฟอร์มเพิ่มคน 3 ขั้น (คน → หน่วยงาน → เวลา) | ✅ มีครบ (เจ้าของสั่งเอง 18 ส.ค. 2569) · ค้นหาชื่อจากบอร์ดได้ · เลือกหน่วยงานแล้วรหัสไซต์ขึ้นเอง |
| ตั้งหลายรอบต่อคน + เบอร์เจ้าหน้าที่รายรอบ | ✅ มี — อาร์เรย์เบอร์ผูกคู่กับรอบอยู่แล้ว |
| แผงการโทร 3 รอบบนหัวหน้า | ✅ มี แต่ยังไม่ใช่ Visual Control ที่กดแล้วเด้งป๊อป |
| ปฏิทิน | ⚠️ มี **แต่คนละหน้าที่** — เป็นตัวกางวันเพื่อ**ติ๊กว่าจะโทรวันไหน**ตอนเพิ่มคน ไม่ใช่ตัวกรองดู |
| บทติดตาม 2 ชุด (สายแรก / รอบถัดไป) | ✅ ขึ้น production แล้ว 31 ส.ค. · ระบบสลับให้เองตามรอบ |

## งานที่ต้องทำ 4 ก้อน

### F1 · ฟอร์มเพิ่มคนย้ายเข้าป๊อป

ตอนนี้ฟอร์มกางอยู่บนหน้าเลย ทำให้หน้าหลักรกและไม่เหลือที่ให้ Planning
⇒ ย้ายเนื้อเดิมทั้งดุ้นเข้าป๊อป กดจากปุ่ม **"เพิ่มคนที่ต้องการติดตาม"**

* 🔴 **ยกของเดิมเข้าไป ห้ามเขียนฟอร์มใหม่** — ฟอร์มนี้มีกติกาที่แลกมาด้วยบั๊กหลายรอบ
  (อาร์เรย์เบอร์ต้องขยับคู่กับรอบเสมอ · ส่งเฉพาะวันที่ติ๊ก ไม่ใช่ทั้งช่วง · กันเวลาซ้ำในวันเดียว)
* 🔴 **ห้ามซ้อน Dialog ใน Dialog** — หน้านี้ไม่ได้อยู่ในป๊อป ใช้ `Dialog` ได้ตรง ๆ
  แต่ dialog ย่อยข้างใน (จัดการเรื่อง/เจ้าหน้าที่) ต้องเป็น `embedded` แบบเดียวกับที่ทำในกล่องงาน
* ✅ **ทำแล้ว 1 ก.ย. 2569** — ขั้น ③ มีบรรทัดโชว์ว่ารอบไหนใช้บทไหน กางดูเนื้อบทได้

### F2 · ปฏิทินกรอง "ดูวันเดียว"

* ปฏิทินตัวใหม่บนหัวหน้า — เลือกวัน = Planning กับ Visual Control กรองเหลือวันนั้น
* 🔴 **คนละตัวกับปฏิทินในฟอร์ม** ห้ามเอามาปนกัน (อันนั้นตั้งว่าจะโทรวันไหน อันนี้ดูย้อน/ดูล่วงหน้า)
* ใช้ `DateRangeCalendarPicker` ที่มีอยู่ (หน้าคลังผู้สมัครใช้อยู่) — เลือกวันเดียวได้ · ล้างแล้วกลับมาดูทั้งหมด

### F3 · ตาราง Planning

**🔴 เจ้าของเคาะ 1 ก.ย. 2569: Planning มา*แทน*รายการการ์ดเดิม ไม่ใช่เพิ่มอีกมุมมอง**
(เพราะที่สั่งคือ "เปิดมาปุ๊บเจอ 3 หลัก ๆ" — มีทั้งสองอย่างจะกลายเป็น 4 ก้อน)

ใครบ้าง · ติดตามวันไหน · กี่รอบ · เวลาไหน — อ่านจบในตาเดียว

* หนึ่งแถว = หนึ่งคน · โชว์ชื่อ · หน่วยงาน · วัน · **ชิปเวลาของแต่ละรอบ** (07:00 · 13:00 · 16:00)
* ชิปเวลาบอกสภาพของรอบนั้นด้วย: ยังไม่ถึงเวลา / ส่งแล้วรอผล / ได้ผลแล้ว (สี)
* ⚠️ ข้อมูลรอบอยู่ที่ `call_times` + สภาพอยู่ที่คิวโทร — ต้องต่อสองที่ ห้ามเดาจากอันเดียว
* เรียงตามเวลานัดที่ใกล้ที่สุดก่อน (คนที่ต้องโทรก่อนอยู่บนสุด)

### F4 · Visual Control บนสุด + กดแล้วเด้งป๊อป

* บอกต่อวัน: **ต้องโทรกี่สาย · โทรไปแล้วกี่สาย · ผลเป็นยังไง**
* กดก้อนไหน → เด้งป๊อปโชว์**รายชื่อจริงในก้อนนั้น** (ไม่ใช่แค่เลขลอย ๆ)
* 🔴 **นิยามถังต้องใช้ของกลาง** `followScheduleCounts` — หน้าแรกใช้ชุดนี้อยู่
  แก้ที่นี่ที่เดียวเมื่อไหร่ เลขสองหน้าจะไม่ตรงกันทันที (เคยเกิดมาแล้วกับกล่องงาน)
* 🔴 ห้ามโชว์ 0 ตอนโหลดพัง — ใช้ `boardDataState` ที่เพิ่งทำในก้อน A ของกล่องงาน

## เรื่องบทพูดต่อรอบ — เคาะแล้ว: **แค่โชว์ ไม่ต้องเลือก**

⚠️ ที่ต้องบันทึกไว้เพราะเกือบขัดกันเอง:

* 31 ส.ค. เจ้าของสั่ง *"บทพูดถ้าแยกตามงานใครงานมันแล้ว ก็ไม่ต้องให้เขาเลือกก็ได้"*
  ⇒ ยกเลิกคลังบท ทำเป็นบทติดตาม **2 ชุดตายตัว** ระบบสลับเอง (ขึ้น production แล้ว)
* 1 ก.ย. สั่ง *"ตอนเลือกรอบให้เลือกด้วยว่ารอบแรกใช้ Scrip อะไร รอบ 2 3 ใช้อะไร"*
* ถามยืนยันแล้ว ⇒ **หมายถึงโชว์ให้เห็นว่ารอบไหนใช้บทไหน กดดูเนื้อบทได้ — ไม่ใช่สร้างคลังบท**

⇒ ในขั้น ③ ของป๊อป แต่ละรอบมีบรรทัดกำกับ เช่น
`รอบ 1 · 07:00 — ใช้บท "ติดตาม — สายแรก"` (กดดูเนื้อบทได้)
`รอบ 2 · 13:00 — ใช้บท "ติดตาม — รอบที่ 2 เป็นต้นไป"`
แก้เนื้อบทยังทำที่หน้าตั้งค่าเหมือนเดิม **ไม่มีการเลือกบทตรงนี้**
