# เอาหน้าสมัครงานไปแปะในเว็บบริษัท (iframe)

อัปเดต 3 ก.ย. 2569

## แบบสั้นที่สุด — คัดลอกไปวางได้เลย

```html
<iframe
  src="https://<โดเมนของระบบ>/apply?embed=1"
  style="width:100%;border:0"
  height="1200"
  title="ตำแหน่งงานที่เปิดรับ"
></iframe>
```

`?embed=1` = **ตัดหัวเว็บ ท้ายเว็บ และพื้นหลังของเราออก** เหลือแต่รายการงานกับปุ่มสมัคร
ให้กลืนไปกับหน้าเว็บของบริษัท · เนื้อหา ตัวกรอง และการสมัคร **ครบเหมือนเดิมทุกอย่าง**

## ให้กรอบสูงตามเนื้อหาเอง (ไม่ต้องเดาความสูง)

หน้าเราจะส่งความสูงกลับไปให้หน้าแม่เรื่อย ๆ วางสคริปต์นี้ในหน้าเว็บบริษัท:

```html
<iframe id="so-jobs" src="https://<โดเมนของระบบ>/apply?embed=1"
        style="width:100%;border:0" height="800"></iframe>
<script>
  window.addEventListener('message', function (e) {
    if (e.data && e.data.type === 'so-recruit:height') {
      document.getElementById('so-jobs').height = e.data.height;
    }
  });
</script>
```

## ฝังเฉพาะบางตำแหน่ง

ต่อตัวกรองท้าย URL ได้ตามปกติ เช่น เอาเฉพาะงานขับรถ:

```
/apply?pos=ขับรถ&embed=1
```

หรือฝังประกาศใบเดียว (ลิงก์ที่ได้จากปุ่ม "สร้างลิงก์"):

```
/apply/p/<รหัสประกาศ>?embed=1
```

## ข้อควรรู้

* **ต้องเป็น https ทั้งสองฝั่ง** — เว็บ https ฝังหน้า http ไม่ได้ เบราว์เซอร์บล็อก
* ผู้สมัครกรอกฟอร์มในกรอบได้เลย ไม่ต้องเด้งออกไปหน้าอื่น
* ข้อความที่เราส่งหาหน้าแม่มี **แค่ตัวเลขความสูง** ไม่มีข้อมูลผู้สมัครติดไปด้วย
* หน้าสาธารณะไม่มีข้อมูลส่วนตัวของพนักงานอยู่แล้ว (ปิดรูไปตั้งแต่ 29 ส.ค. 2569)

## สิ่งที่ยังไม่ได้ทำ — รอเจ้าของสั่ง

ตอนนี้ระบบ **ไม่ได้กันไม่ให้ใครเอาหน้าอื่นไปฝัง** ด้วย แปลว่าหน้าที่ต้องล็อกอิน
ก็ถูกเอาไปใส่ iframe ได้เหมือนกัน (ความเสี่ยง: เว็บปลอมเอาหน้าจริงไปครอบแล้วหลอกให้กด)
ถ้าต้องการ ผมล็อกให้ฝังได้เฉพาะ `/apply` ได้ — ต้องแก้ไฟล์ตั้งค่าการ deploy
