## สรุปสำหรับคนอ่าน (ไม่ต้องคัดลอก)

### เสร็จไปแล้วช่วง 29 ส.ค. – 1 ก.ย. 2569

| เรื่อง | ผล |
|---|---|
| ข้อมูลส่วนตัวรั่วหน้าประกาศสาธารณะ | อุดแล้ว — ชื่อคน 102 / เบอร์ 32 / ทะเบียนรถ 20 → เหลือ 0 |
| กล่องงานโชว์ 0 ตอนโหลดพัง | แก้แล้ว — พังขึ้น "—" + ปุ่มลองใหม่ · ปุ่มส่งชุดหาย |
| กล่องงานเปิดช้า/ตายบ่อย | เพิ่มสำเนาอายุสั้น · ต่อไม่ติดแต่มีสำเนา = เสิร์ฟของเก่าพร้อมบอกอายุ |
| การ์ดกล่องงานบอกขั้น + % | ทำแล้ว (100% = ปล่อยขึ้นสาธารณะ) |
| ป๊อปติ๊กอัตราจากใบขอเข้ารายการรายได้ | ทำแล้ว — อัตราเบิกไม่ขึ้นประกาศ · บรรทัดค่าปรับติดป้ายเตือน |
| บทติดตามแยกสายแรก / รอบ 2 | ทำแล้ว · แก้บทได้ที่หน้าตั้งค่า |
| ฟอร์มเพิ่มคนหน้าติดตามย้ายเข้าป๊อป | ทำแล้ว + บอกว่ารอบไหนใช้บทไหน กางดูได้ |
| คลังผู้สมัคร ถอดกราฟแท่ง 12 เดือน | ทำแล้ว เหลือปฏิทินอย่างเดียว |

### ยังไม่ทำ — เรียงตามที่ตกลงกัน

1. **หน้าติดตาม F3** ตาราง Planning (แทนการ์ดเดิม) → **F2** ปฏิทินกรองวัน → **F4** Visual Control กดแล้วเด้งป๊อป
2. **กล่องงาน ก้อน B** ยุบเส้นเดินเหลือ 3 ขั้น · ปุ่ม "ถัดไป" = การตรวจ · ใบไม่ผ่านตรวจส่งไม่ได้
   ⚠️ ก้อนนี้ทำให้เลขบนหัวกล่องงานเปลี่ยนชุด และแถบขั้นบนการ์ดเปลี่ยนจาก 1-4 เป็น 1-3
3. **กล่องงาน ก้อน C** ภาษาปุ่ม 3 ระดับ · เลขอธิบายตัวเองบนจอ · โชว์ว่าใบไหนมีคนสมัครกี่คน

### บั๊กที่รู้แล้วแต่ยังไม่แก้

* **แดชบอร์ด "คงเหลือ" นับซ้ำสองเท่า** — ภาระงานตามไซต์บอก 367 แต่ตามผู้รับผิดชอบบอก 734
  (ใบเดียวมีทั้งเจ้าหน้าที่สรรหาและคัดสรร เลยบวกอัตราเดียวกันสองรอบ)
* **ป้าย "ทั้งระบบ" โกหกตอนกรอง** — กรองเดือนก่อนแล้วยังเขียนว่า "คงเหลืองานทั้งระบบ"
  ทำให้อ่านแล้วเทียบผิดจนสรุปว่างานค้างพุ่ง 616% ซึ่งไม่จริง
* หน้าแรก "ต้องลงมือ 3 เรื่อง" ยังมีปุ่มนำทางปุ่มเดียว — ตัวจำลองขอให้บอกชัดว่าวันนี้ทำอะไร 1-2-3

### เรื่องที่เคยสั่งกลับไปกลับมา — อย่าทำผิดซ้ำ

* **คลังบทพูด: ยกเลิกแล้ว** — ระบบเลือกบทเองตามสถานการณ์ · หน้าติดตามแค่ **โชว์** ว่ารอบไหนใช้บทไหน
* **สวัสดิการช่องพิมพ์: เจ้าของสั่งเองให้เป็น freetext เมื่อ 20 ส.ค.** — ที่เพิ่มเข้ามาใหม่คือ
  ติ๊กจาก **ตารางอัตรา** ซึ่งคนละเรื่องกับชิปสำเร็จรูป 12 อันที่ถูกถอดไป
* **Planning มาแทนการ์ดเดิม** ไม่ใช่เพิ่มอีกมุมมอง (เจ้าของเคาะ 1 ก.ย.)
