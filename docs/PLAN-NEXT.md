## งานที่ทำได้เลย (เรียงตามที่ควรทำก่อน)

### 1. ล็อกคนข้ามใบ + เสนอทีละงาน — **ทำแล้ว 2 ใน 3 ส่วน**

เจ้าของเคาะกติกาไว้ครบแล้ว:
- คนเดียวแมทได้หลายใบ → **เสนอทีละใบ เรียงตามคะแนนแมทของคนนั้น**
- ได้คำตอบว่า "สนใจใบ A" → **บังใบอื่นจนกว่าใบ A จะจบ**

✅ **ทำแล้ว** (`2833d41` + `9cafc7b`) — กัน 3 ชั้นใน `TAKE_PENDING_SQL`:
1. สายกำลังเดิน · 2. ใบที่มาก่อนได้ก่อน · 3. สนใจใบไหนแล้วบังใบอื่น (เพดาน 7 วัน)
วัดกับฐานจริง: reminder ถึงคิว 2,816 แถว → เสิร์ฟ 126 แถว = 126 คน
(เจอบั๊กระหว่างทาง: ล็อก "รับไปโทรเอง" + พักเบอร์ ไม่เคยมีผลกับช่อง interview เลย — แก้แล้ว)

⛔ **ยังไม่ได้ทำ: เรียงตามคะแนนแมท** — ตอนนี้เรียงตาม "ใบที่เข้าคิวก่อน"
ติด 2 เรื่องที่ต้องให้เจ้าของเคาะ:

| เรื่อง | ทางเลือก |
|---|---|
| **ใช้คะแนนไหน** | ก) **tier ของ AI** (เขียว/เหลือง/แดง) — มีฝั่ง server อยู่แล้วทั้งเส้น auto และเส้นคนติ๊กเลือก (`getStoredBoardMatch`) · ข) **% ที่เห็นบนการ์ด** (เช่น 44%) — คิดฝั่งเบราว์เซอร์ด้วย `scoreCandidatePriority` (อายุ/ที่อยู่/ประสบการณ์/รายได้) ฝั่ง API ไม่มี ต้องให้หน้าเว็บส่งมาตอนกดส่ง |
| **ต้องรัน migration บนฐาน** | คิวไม่มีที่เก็บคะแนน ต้องเพิ่มคอลัมน์ `match_rank` แล้วรัน `node scripts/migrate.mjs` — **ฐาน local = production** จึงไม่รันเองโดยไม่ได้สั่ง (ใส่ payload แทนไม่ได้ — payload ถูกส่งให้ Lumos ตรง ๆ ฟิลด์แปลกปลอมอาจทำให้ schema ไม่ผ่าน) |
