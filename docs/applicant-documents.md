# ส่งเอกสารผ่าน LINE

ผู้สมัครถ่ายบัตรประชาชน ใบขับขี่ ทะเบียนบ้าน ตรวจข้อมูล ตอบเอกสาร 5 ฉบับ แล้วเซ็นส่งจากมือถือ HR เปิดดูชุดที่ส่งในแท็บ "เอกสาร"

## เจ้าหน้าที่ใช้ยังไง

1. เปิดผู้สมัคร › แท็บข้อมูลผู้สมัคร › กล่อง "ส่งเอกสาร" › กด "ส่งเอกสาร"
2. กด "คัดลอก" แล้ววางส่งให้ผู้สมัครใน LINE (ระบบไม่ส่งให้เอง) · ลิงก์ใช้ได้ 24 ชั่วโมง ส่งได้ 1 ชุด
3. ผู้สมัครส่งแล้ว กระดิ่งของคนสร้างลิงก์ขึ้น "ส่งเอกสารแล้ว"
4. เปิดแท็บ "เอกสาร" › กดชื่อ › ดูข้อมูล ภาพ PDF ทุกฉบับ
5. ข้อมูลผิด: พิมพ์ในช่อง "ต้องแก้อะไร" › "ทำเครื่องหมายต้องแก้ไข" แล้วส่งลิงก์ใหม่ให้
6. คีย์ใน iRecruit แล้ว: เลือกแผนก › ใส่เลขที่ผู้สมัคร › "บันทึกเลขที่ iRecruit"

## Admin ต้องตั้งก่อนเปิด (ตั้งค่า › ส่งเอกสารผ่าน LINE)

1. LINE Developers: สร้าง LINE Login channel แล้วเพิ่ม LIFF app (สิทธิ์ `openid` + `profile` เท่านั้น · Endpoint URL = `https://<โดเมนระบบ>/apply/documents`)
2. ใส่ Channel ID กับ LIFF ID ในหน้าตั้งค่า (สองค่านี้ไม่ใช่ความลับ ไม่ต้องใช้ token)
3. อัปโหลดต้นฉบับเอกสาร 5 ฉบับ (ภาพ PNG/JPG ทีละหน้า) · อัปโหลดใหม่ = รุ่นใหม่ ชุดที่ส่งแล้วจำรุ่นเดิม
4. รัน migration 195 บนฐานจริงก่อนเปิดสวิตช์
5. เปิดสวิตช์ "เปิดใช้" (ตั้งค่าไม่ครบ ระบบไม่ให้เปิด)

## ข้อจำกัดที่ต้องรู้

- LINE ยืนยันว่าเป็นบัญชี LINE ไหน ไม่ได้ยืนยันว่าเป็นเจ้าของบัตร · ส่งแทนผู้สมัครได้ แต่ระบบจดไว้ว่า "ส่งแทน"
- อ่านภาพ (OCR) บนมือถือผู้สมัคร ไม่ส่งภาพไปบริการอ่านภาพข้างนอก · อ่านไม่ชัดช่องจะว่างให้กรอกเอง ผู้สมัครต้องติ๊กยืนยันว่าตรวจแล้ว
- ภาพและข้อมูลในชุดเข้ารหัสในฐาน · คำขอลบข้อมูลส่วนบุคคล (PDPA) ล้างภาพและข้อมูลในชุดด้วย
- PDF = ต้นฉบับที่ผู้สมัครอ่าน + หน้าแนบท้ายข้อมูล คำตอบ ลายเซ็น (ยังไม่ได้พิมพ์ลงช่องในกระดาษต้นฉบับ)
