# โลโก้ SO บนหน้าสาธารณะ — วางไฟล์ตรงไหน

เจ้าของสั่ง 17–18 ส.ค. 2569: เอาโลโก้ SO (ตัว S แดง + วง O) ขึ้นหัวบอร์ดสาธารณะ
และทำเป็น **พื้นหลังจาง ๆ** ด้วย

## ต้องทำอย่างเดียว: เซฟไฟล์

```
public/so-logo.png
```

เซฟรูปโลโก้ SO ไว้ที่ path นี้ แล้ว **ขึ้นเองทั้งสองที่ ไม่ต้องแก้โค้ด**

* พื้นหลังจาง ๆ ของหน้า `/apply` (จาง 5% ในโหมดสว่าง · 3% ในโหมดมืด)
* หัวบอร์ดสาธารณะ (แทนข้อความ "ค้นหางานที่เหมาะกับคุณ")

**แนะนำ:** PNG พื้นหลังโปร่ง (transparent) ด้านกว้างอย่างน้อย ~800px
พื้นทึบก็ใช้ได้ แต่ลายน้ำจะเห็นเป็นสี่เหลี่ยมจาง ๆ แทนที่จะเป็นรูปโลโก้ล้วน

## ตอนนี้ยังไม่มีไฟล์แล้วเป็นยังไง

ออกแบบให้ **ไม่พังและไม่โชว์ของผิด**:

* พื้นหลัง — ใช้ CSS `background-image` ไฟล์ไม่มีก็แค่ไม่ขึ้น ไม่มีรูปแตก
* หัวบอร์ด — ถอยไปใช้ **หัวข้อข้อความเดิม** ("ค้นหางานที่เหมาะกับคุณ")
  ⚠️ **จงใจไม่ถอยไปใช้ `so-work-logo.png`** — นั่นคือโลโก้ "SO WORK!" พื้นแดง
  ซึ่งเป็นคนละตัวกับที่เจ้าของส่งมา · เอาโลโก้ผิดตัวขึ้นบนหน้าที่คนนอกเห็น
  = ให้ข้อมูลผิด แย่กว่าไม่มีโลโก้

## อย่าสับสนกับ `public/so-work-logo.png`

ไฟล์นั้นคือโลโก้ "SO WORK!" พื้นแดง ใช้เป็น **โลโก้แบรนด์บนแถบเมนู** (ไอคอน 32px มุมซ้ายบน)
และเป็นค่าเริ่มต้นของระบบ branding — **คนละตัว คนละที่ใช้** ห้ามเอามาทับกัน
