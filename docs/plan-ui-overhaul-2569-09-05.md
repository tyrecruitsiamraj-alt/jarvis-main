## ภาษากลางที่ทุกหน้าต้องพูด (สรุปจากหน้า Login + บทเรียน valley-clone)

1. **ผืนเดียวต่อเรื่อง** — หนึ่ง section = การ์ดใหญ่ใบเดียว ข้างในคั่นด้วย **เส้นบาง** (hairline)
   ห้ามกล่องซ้อนกล่อง (ต้นเหตุความ "สะเปะสะปะ/ตลก" ที่เจ้าของทักซ้ำ ๆ)
2. **สีเน้นสีเดียว = เบอร์กันดี** — ต่อหน้าหนึ่งมีปุ่ม primary เด่นได้ปุ่มเดียว
   สีอื่นที่เหลือ = สีที่มีความหมายของตัวเลขเท่านั้น (เขียว/เหลือง/แดง/ฟ้า/ม่วง — ห้ามแตะ)
3. **แถวตัวเลขแบบเดียวทั้งระบบ** — เลขใหญ่ `tabular-nums` + ป้ายจิ๋ว uppercase ช่องไฟกว้าง
   (แบบ stat row ของ valley แต่เป็น Kanit) แทนกล่อง stat จิ๋วหลายทรงที่มีอยู่ ~5 แบบ
4. **ลำดับงานใช้เลข 01–04 + เส้นเชื่อม** ภาษาเดียวกับรางสายพานหน้า Login
5. **เคลื่อนไหวเท่าที่จำเป็น** — fade-up ตอนเข้าหน้า/hover เท่านั้น · **ห้ามแอนิเมชันวนไม่จบ**
   (เพิ่งรื้อเรดาร์/เส้นสแกน/หมอกออกเพราะเว็บกระตุก — ห้ามกลับมา)
6. เครื่องมือ: shadcn + Tailwind utilities + token ธีมเท่านั้น · **ห้ามเขียน CSS ใหม่** ·
   ฟอนต์ Kanit เดียว · ทุกเฟสรันเทสต์เต็ม + ดูบนจอจริง (สว่าง/มืด/มือถือ) ก่อน push

## ของกลางที่จะสร้างก่อน (เฟส 1) — ประกอบจาก shadcn ไม่มี CSS ใหม่

- `PageSection` — เปลือก section มาตรฐาน: หัวเรื่อง + คำอธิบาย + ผืนเดียว
- `StatRow` / `StatCell` — แถวตัวเลขมาตรฐาน (แทน `jarvis-stat-tile` หลายทรง)
- `HairlineList` — รายการคั่นเส้นบาง (แทนกล่องย่อย)
- ปรับ `PageHeroStrip` ให้บางลง: แถบขาว เส้นคั่น ไม่ใช่ผืนกรมท่าทึบทุกหน้า
