# API ดึงผลแบบทดสอบ (สำหรับทีม iRecruit)

ใช้ดึงผลแบบทดสอบทักษะของคนที่ทำแบบทดสอบผ่านลิงก์ของ Jarvis

## เรียกที่ไหน

```
GET https://jarvis.siamrajathanee.dev/api/integrations/irecruit/skill-results
```

ทุกคำขอต้องส่ง header นี้ (ทีม Jarvis ส่งกุญแจให้แยกต่างหาก)

```
x-api-key: <กุญแจที่ได้รับ>
```

ไม่ส่งกุญแจหรือกุญแจผิด จะได้ `401`

## พารามิเตอร์

| ชื่อ | ใช้ทำอะไร | ตัวอย่าง |
|---|---|---|
| `since` | ดึงผลที่ส่งคำตอบหลังเวลานี้ ใช้ครั้งแรกครั้งเดียว ไม่ส่ง = ตั้งแต่ผลแรก | `2026-11-01T00:00:00+07:00` |
| `cursor` | ดึงต่อจากรอบก่อน ใส่ค่า `next_cursor` ที่ได้รอบล่าสุด (ใช้แทน `since`) | `MjAyNi0xMS0x...` |
| `phone` | เฉพาะเบอร์นี้ 10 หลัก | `0812345678` |
| `limit` | จำนวนต่อรอบ 1–500 ค่าเริ่ม 100 | `100` |

## วิธีดึงให้ครบไม่ซ้ำ

1. รอบแรก เรียกพร้อม `since` (หรือไม่ใส่ เพื่อเอาทั้งหมด)
2. เก็บ `next_cursor` ที่ได้ไว้
3. รอบถัดไป เรียกพร้อม `cursor=<ค่าที่เก็บไว้>`
4. ถ้า `has_more` เป็น `true` ให้เรียกต่อทันทีจนกว่าจะเป็น `false`
5. ไม่มีผลใหม่ จะได้ `items` ว่าง และ `next_cursor` ค่าเดิม เก็บไว้ใช้รอบหน้าได้เลย

## ตัวอย่างคำตอบ

```json
{
  "items": [
    {
      "id": "6f1c2a9e-4b7d-4c2a-9e1f-3a5b7c9d0e12",
      "doc_no": "SO-TECH-00125",
      "set": { "id": "2b4d6f80-...", "title": "ช่างไฟฟ้าอาคาร ระดับ 1", "role": "ช่างไฟฟ้า" },
      "person": { "first_name": "สมชาย", "last_name": "ใจดี", "phone": "0812345678" },
      "submitted_at": "2026-11-17T03:15:00.123Z",
      "status": "review",
      "status_label": "รอตรวจ",
      "reviewed_at": null,
      "pass_score": 70,
      "score": 67,
      "grade": "C",
      "passed_skills": 1,
      "total_skills": 2,
      "passed": false,
      "skills": [
        { "name": "ไฟฟ้ากำลัง", "score": 50, "passed": false },
        { "name": "ความปลอดภัย", "score": 100, "passed": true }
      ],
      "result_url": "https://jarvis.siamrajathanee.dev/skill-test?set=2b4d6f80-...&open=6f1c2a9e-..."
    }
  ],
  "next_cursor": "MjAyNi0xMS0xN1QwMzoxNTowMC4xMjM0NTZafDZmMWMy...",
  "has_more": false
}
```

## ความหมายของแต่ละช่อง

- `score` คะแนนรวม 0–100 · `grade` A/B/C/D ตามเกณฑ์ของชุด
- `passed` = ผ่านทุกทักษะ (คะแนนแต่ละทักษะไม่ต่ำกว่า `pass_score`)
- `status` = `review` (รอเจ้าหน้าที่ตรวจ) หรือ `ready` (ตรวจแล้ว พร้อมส่ง) · คะแนนไม่เปลี่ยนหลังส่งคำตอบ
- `result_url` เปิดใบผลในระบบ Jarvis ได้เฉพาะคนที่มีบัญชี Jarvis และมีสิทธิ์ดูชุดนั้น
- ส่งเฉพาะผลที่ส่งคำตอบแล้ว ผลที่เจ้าหน้าที่ลบแล้วจะไม่ส่งมา

## ข้อมูลที่ไม่ส่ง

ไม่ส่งเลขบัตรประชาชน วันเกิด คำตอบรายข้อ และบทวิเคราะห์ (ข้อมูลส่วนบุคคล ส่งเท่าที่ใช้)

## ข้อผิดพลาด

| รหัส | เมื่อไหร่ |
|---|---|
| `400` | พารามิเตอร์ผิด (ข้อความบอกว่าผิดช่องไหน) |
| `401` | ไม่ส่งกุญแจ หรือกุญแจผิด/ถูกยกเลิก |
| `503` | ฝั่ง Jarvis ยังไม่ได้ออกกุญแจ |
| `500` | ฝั่ง Jarvis อ่านข้อมูลไม่ได้ ลองใหม่ภายหลัง |
