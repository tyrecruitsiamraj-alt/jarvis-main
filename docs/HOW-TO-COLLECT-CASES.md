# วิธีเก็บเคสจากคนเก่ง — ให้ skill โคลนแม่นขึ้น

**ใช้เวลาคนเก่ง 1 ชั่วโมงต่อคน จบ** ไม่ต้องเขียนเอกสาร ไม่ต้องเตรียมตัว

---

## หลักคิด: อย่าให้เขา "เขียนวิชา" ให้เขา "ตัดสินใจแล้วเล่าว่าทำไม"

ถ้าถามว่า "ช่วยเขียนหลักการทำงานให้หน่อย" — จะได้คำตอบกว้าง ๆ ที่ใคร ๆ ก็พูดได้
เพราะความรู้จริงอยู่ในมือ ไม่ได้อยู่ในปาก

**วิธีที่ได้ผล:** เอาเคสจริงวางตรงหน้า → ให้เขาตัดสิน → ถามว่าทำไม
ตอนตัดสินจริงเขาจะพูดสิ่งที่ตัวเองไม่เคยรู้ว่ารู้

---

## ขั้นตอน (ทำครั้งเดียวต่อคน)

### 1. เตรียมเคส — ผมทำให้ได้ ไม่ต้องหาเอง

บอกผมว่า "ขอเคสสำหรับ [ชื่อ skill]" ผมจะดึงจากระบบจริงให้ เช่น

* **แปลงใบขอ** → ใบขอจริง 15 ใบ คละแบบ (ลาออก/เปิดไซต์/เพิ่มอัตรา ·
  หาง่าย/หายาก · เจ้านายไทย/ญี่ปุ่น)
* **เลือกคนที่สมัครแล้ว** → ใบขอที่มีผู้สมัครหลายคน พร้อมข้อมูลแต่ละคน
  **และผลจริงว่าสุดท้ายใครได้งาน อยู่กี่เดือน** ← ตัวนี้มีค่าที่สุด
* **หาคนจากฐาน** → ใบขอที่ AI หาคนไม่เจอจริง ๆ
* **ผู้จัดการตามงาน** → ภาพ Dashboard ย้อนหลัง 5 วันที่งานค้างเยอะ

### 2. นัดคนเก่ง 1 ชั่วโมง — ถาม 3 คำถามเดิมทุกเคส

เปิดเคสให้ดูทีละอัน แล้วถาม:

> **1. "ดูอะไรก่อน"** — อะไรคือสิ่งแรกที่ตาไปเกาะ
> **2. "ตัดสินยังไง แล้วเพราะอะไร"** — ให้เขาพูดเหตุผลออกมาดัง ๆ
> **3. "เคยพลาดแบบไหน"** — เคสที่หน้าตาเหมือนกันแต่จบไม่เหมือนกัน

**อัดเสียงไว้** ไม่ต้องจด — ให้เขาพูดอย่างเดียว จดแล้วจะพูดน้อยลง

### 3. คำถามพิเศษต่อ skill (ถามท้ายสุด)

| skill | ถามเพิ่มว่า |
|---|---|
| แปลงใบขอ | "ใบขอแบบไหนที่พออ่านแล้วรู้เลยว่าจะหายาก" |
| เลือกคนที่สมัครแล้ว | "คนแบบไหนที่ดูดีมากแต่สุดท้ายออกเร็ว" |
| หาคนจากฐาน | **"ถ้าต้องยอมหย่อนเกณฑ์ จะหย่อนอะไรก่อน"** ← สำคัญสุด ถามให้ได้ |
| ผู้จัดการตามงาน | "จี้แบบไหนได้ผล จี้แบบไหนยิ่งช้า" |
| คนทำระบบ | "เคยแก้อะไรแล้วพังโดยไม่คาดคิด" |

### 4. ส่งมาให้ผม

อัดเสียง / พิมพ์คร่าว ๆ / เล่าให้ผมฟังในแชตก็ได้ — ผมเอาไปเติมลง skill ให้เอง
**ไม่ต้องเรียบเรียง** พูดตามที่จำได้พอ

---

## เคล็ดที่ทำให้ได้ของจริง

**ถามเคสที่เขา "พลาด" ด้วย** ไม่ใช่แค่เคสที่สำเร็จ
ความรู้ที่มีค่าที่สุดอยู่ในความผิดพลาด — คนมักไม่เล่าถ้าไม่ถามตรง ๆ

**ให้เขาตัดสินก่อนเห็นเฉลย** ถ้าเคสมีผลจริงอยู่แล้ว (เช่น คนนี้อยู่ 2 เดือนแล้วออก)
อย่าเพิ่งบอก ให้เขาทายก่อน แล้วค่อยเปิดเฉลย — ตอนที่เขาทายผิดคือตอนที่ได้ความรู้เยอะที่สุด

**สองคนเก่งอาจตอบไม่เหมือนกัน** ไม่ต้องบังคับให้ตรงกัน
บันทึกทั้งสองแบบพร้อมเหตุผล แล้วให้เจ้าของเลือกว่าจะยึดแบบไหน

---

## ทำเสร็จแล้วได้อะไร

skill จะเลิกเดาจากกติกาในระบบ แล้วเริ่มคิดแบบคนเก่งจริง ๆ
เอาไว้ **สอนคนใหม่** ได้ด้วย — คนเข้าใหม่ถาม skill แทนที่จะไปรบกวนคนเก่งทุกครั้ง

> ⚠️ ยังไงก็ยังไม่แทนคนจริง — ใช้เป็นตัวช่วยคิดกับตัวสอนงาน ไม่ใช่ตัวตัดสินใจแทน

## นัดทบทวน

ไตรมาสละครั้งพอ — เอาเคสใหม่มาให้ทั้งคนจริงและ skill ตอบ แล้วดูว่าต่างกันตรงไหน
ตรงที่ต่างคือของที่ต้องเติม
