# หน้าทีม Online — แผนและสถานะ (29 ก.ย. 2569)

## ที่มา

เจ้าของ: *"หน้าหลัก ฉันจะเริ่มแก้ใหม่ เพราะตอนนี้บอกได้งงมาก อันนี้ฉันจะเริ่มจากทีม Online"* พร้อมภาพต้นแบบ

เจ้าของเลือก Choice ไว้ 4 ข้อ

| คำถาม | คำตอบของเจ้าของ |
| --- | --- |
| ทำแค่ไหน | **ทำตามภาพด้วยข้อมูลจริง ดูหลังสวิตช์ก่อน** |
| คนใช้งาน คือใคร | **เจ้าหน้าที่ที่เข้าใช้ระบบ** |
| อนุมัติ / เผยแพร่ | *"ใบที่ Genlink มันก็ไปหน้าสาธารณะหนิ"* ⇒ ใช้ **ใบที่ Gen link แล้ว** |
| ความคุ้มค่า | **เว้นไว้ก่อน** ⇒ แท็บกดไม่ได้ |

## วิธีเปิดดู

1. ล็อกอินเว็บจริงตามปกติ
2. เข้า `/?home=online`
   - ระบบจำไว้ในเครื่อง เปิดหน้าหลักครั้งต่อไปก็ได้หน้านี้
   - กลับหน้าเดิมด้วย `/?home=classic`
   - หน้าเดิมยังเป็นค่าตั้งต้นของทุกคน (ทางถอย)

## ในหน้า (ตามภาพ)

**หัวหน้า**
- ช่วงเวลา: วันนี้ / สัปดาห์นี้ / เดือนนี้ / ปีนี้
  - ทุกช่วงนับถึงตอนนี้ แล้วเทียบกับช่วงก่อนที่นับถึงจุดเดียวกัน
  - เช่น วันนี้ถึง 12:00 เทียบเมื่อวานถึง 12:00
- ตัวเลือก "รายละเอียด BU"
- บรรทัดบอกช่วงที่กำลังดู

**5 การ์ด**
1. คนใช้งาน · ทุก BU
2. ใบขอเข้า
3. Lumos โทรแล้ว
4. Success ประกาศ
5. Success โทร · สนใจ

**ส่วนอื่นของหน้า**
- **แถบสิ่งที่ต้องจับตา**
  - สรุปเอง: เรื่องที่ขยับมากที่สุด 2 เรื่อง + งานที่ต้องทำ
  - ปุ่ม "ตรวจคิวโทร N สาย" เปิดป๊อปเดิมของหน้าหลัก
- **กราฟ**: เส้นทึบ = ช่วงนี้ · เส้นประ = ช่วงก่อน
  - เลือกเส้นได้ 4 แบบ: คนใช้งาน / ใบขอเข้า / Lumos โทรแล้ว / Gen link ใหม่
- **แผง "BU ไหนงานเยอะ แล้วได้ผลแค่ไหน"**
  - แสดงทุก BU เสมอ
  - กดชื่อ BU = ตั้งตัวกรองของทั้งหน้า
- **แท็บ**
  - ผลลัพธ์ / Success: ตารางตามภาพ
  - ใบขอและงานค้าง
  - Lumos
  - งานต้องทำ
  - ความคุ้มค่า (ปิดไว้)

⚠️ ภาพต้นแบบเห็นแค่แท็บแรก ⇒ **แท็บ 2–4 เป็นร่างแรกของผม** รอเจ้าของดูแล้วสั่งปรับ

## นิยาม (ตัวคิดอยู่ `src/lib/teamOnline.ts` ที่เดียว)

| ตัวเลข | นิยาม |
| --- | --- |
| คนใช้งาน | คนไม่ซ้ำที่ล็อกอินหรือบันทึกงานในช่วงนั้น (ร่องรอยจาก 20 คู่ตาราง) · ทุก BU เสมอ |
| ใบขอเข้า | เลขที่ใบไม่ซ้ำตามวันที่กรอกใบ · มาจากสำเนา ERP ก้อนเดียวกับแท็บ Dashboard |
| Lumos โทรแล้ว | ผู้สมัครจากหน้าสมัครงาน (เลน `app-`) ที่มีสายในช่วง · นับคน |
| ติดต่อได้ · สนใจ · ไม่รับสาย | ดูจากสายล่าสุด · ใช้ตัวจัดถังเดียวกับหน้าหลัก |
| Success ประกาศ | ใบที่ Gen link ครั้งแรกในช่วงที่มีผู้สมัครอย่างน้อย 1 คน ÷ ใบที่ Gen link ในช่วง |
| ผู้สมัคร | ไม่นับ Lead · ตัวเดียวกับเลขบนการ์ดกล่องงาน |
| Success โทร | สนใจ ÷ ติดต่อได้ |

## ธงคุณภาพข้อมูลที่ต้องขึ้นเสมอ

- **ข้อมูลเพิ่งเริ่ม**: ล็อกเริ่ม 1 ก.ค. · ประกาศเริ่ม 5 ส.ค. · สายเลนหน้าสาธารณะมีผลแรก 23 ก.ย.
  - ช่วงก่อนที่ยังไม่มีข้อมูลขึ้นว่า "ช่วงก่อนยังไม่มีข้อมูล" (ไม่ใช่ 0) และไม่วาดเส้นประ
  - ช่วงที่ข้อมูลเริ่มกลางทางติดธง "ข้อมูลเริ่ม …"
- **ERP มีแต่วันที่ ไม่มีเวลา**
  - วันนี้เทียบเมื่อวานทั้งวัน
  - กราฟรายชั่วโมงของใบขอเข้าทำไม่ได้
- **สำเนา ERP เก่า** ⇒ ขึ้นว่า "ข้อมูลใบขอยังไม่อัปเดตรอบล่าสุด"
- **ใบที่ไม่รู้ BU** (ใบขอล่วงหน้า 11 ใบ) ขึ้นเป็นแถว "ไม่ระบุ BU"
  - ยอดรวมจึงตรงหัวกล่องงาน

## สิ่งที่ยังไม่ได้ทำ / รอเจ้าของ

- เจ้าของเปิดดูด้วยตา แล้วสั่งปรับ
  - ผมเข้าหลังหน้า Login เองไม่ได้ ตรวจได้แค่ render test + ยิงตัวคิดบนฐานจริงแบบอ่านอย่างเดียว
- แท็บ 2–4 (ร่างแรก) · แท็บความคุ้มค่า (เว้นไว้ตามสั่ง)
- ทีมอื่นของหน้าหลัก (เจ้าของบอกจะเริ่มจากทีม Online ก่อน)
- โฉม 3 ก้อน (`?home=v3`) ยังอยู่หลังสวิตช์
  - ถอดออกเมื่อหน้าใหม่ของเจ้าของมาแทน

## รอบ 2 (29 ก.ย. 2569 บ่าย) — เจ้าของเปิดดูแล้วสั่งต่อ

คำสั่ง 4 ข้อ + *"ช่วยคิดต่อเพิ่มให้หน่อย"* · หน้านี้ใช้หลักคือ User และผู้บริหาร —
*"user ต้องรู้ว่าต้องทำอะไรต่อ ผู้บริหารรู้เลยว่าอ้อทีมนี้ยังไม่ใช้ อ้อใช้แล้วติดตรงนี้ อ้อคนใช้ลดลง"*

| ข้อ | ที่ทำ |
| --- | --- |
| 1. ช่วงเวลาเป็นปฏิทิน | แถบเดียวกับแท็บ Dashboard: วัน/สัปดาห์/เดือน/ไตรมาส/ปี + ปฏิทินเลือกช่วง + เทียบช่วงก่อน/ปีก่อน |
| 2. คนใช้งานเทียบ BU เป็น % | % ของบัญชีใน BU (เจ้าของเลือก) + แยกบทบาท เจ้าหน้าที่/หัวหน้า/OPL/ผู้ดูแลระบบ · แท่งต่อช่วงย่อย + เส้นแนวโน้มต่อ BU |
| 3. ใบขอเข้าเหมือนข้อ 2 | นับเป็นอัตรา (เจ้าของเลือก) · แท่ง + เส้นแนวโน้มต่อ BU · ตารางมีใบ/เปิดอยู่/เหลือหา/ยังไม่ Gen link |
| 4. Lumos ต่อ BU | ทุกเลน แยกสีตามเลน (เจ้าของเลือก) · ส่งไป · รอโทร · โทรแล้ว · สำเร็จ · ไม่สำเร็จ · Success rate (ตัวเดียวกับ Dashboard) |
| คิดต่อ (เจ้าของเลือก 2 จาก 4) | **ติดตรงไหน ต่อ BU** (ใบขอเข้า → Gen link → มีผู้สมัคร → AI โทร → สนใจ → นัด → มาตามนัด) · **งานที่ต้องทำต่อของคนเปิด** |

ตัวเลขจริงตอนทำ (30 วันล่าสุด):
- **ใช้ระบบ:** LBD ใช้ 27/37 บัญชี (73%) · LBA 6/11 · DS 4/4 · **LM 0/4 (ช่วงก่อน 100%)** · SN ยังไม่มีบัญชี
- **Lumos:** มีแต่ LBD ที่ส่งงานให้ Lumos (ติดตามก่อนเริ่มงาน 528 · ผู้สมัครหน้าสาธารณะ 77) · Success rate 85%
- **ติดตรงไหน:** ทุก BU ติดที่ Gen link (LBD 125 ใบ → Gen link 5 → มีผู้สมัคร 4 → AI โทร 4 → สนใจ 4 → นัด 4)
  - ⚠️ **"นัด 4" ผิด แก้แล้วในรอบ 4** — เคยนับผลสายสัมภาษณ์ AI (`confirmed`) เป็นนัด · ของจริง = นัด 0 (ติดที่นัด)

ข้อมูลที่ระบบยังไม่มี (ขึ้น "—" ไม่ใช่ 0):
- ผล "มาตามนัด" ยังไม่เคยถูกบันทึก
- การเปิดดูหน้าจอ (คนใช้งานนับจากล็อกอิน + งานที่บันทึก)



## รอบ 4 (29 ก.ย. 2569 ค่ำ) — การ์ดกดได้ · ผู้สมัคร · ใบยังไม่มีผู้สมัคร · มุมเจ้าหน้าที่

เจ้าของถาม *"ถ้านายเป็นผู้บริหาร อ่านแล้วตอบได้หมดไหม ถ้าเป็น User รู้ไหมต้องทำงานอะไร"* + *"การ์ด … กดไปไม่มีไรเลย"*
แล้วตามด้วย *"มีรายชื่อมา มาจากไหน มาแล้วยังไง แล้วใบที่ยังไม่มาเยอะแค่ไหน นานแค่ไหน แต่ละ bu เป็นยังไง"*

| เรื่อง | ที่ทำ |
| --- | --- |
| การ์ดกดได้ (Choice: แผงเลื่อนออกด้านขวา) | กดทั้งใบ → แผงด้านขวา ตามการ์ด: คนใช้งาน → % ต่อ BU + บทบาท + รายชื่อ · ใบขอเข้า → ต่อ BU + ติดตรงไหน · ผู้สมัครใหม่ → มาจากไหน/มาแล้วยังไง + ใบยังไม่มีผู้สมัคร · Lumos → ตารางทุกเลน · Success ประกาศ → ใบที่ได้ผู้สมัคร + ใบเงียบ |
| รายชื่อ (Choice: เห็นรายชื่อแยก BU) | เฉพาะหัวหน้า/admin (เซิร์ฟเวอร์ตัดสิน) · คนที่ยังไม่ได้ใช้ขึ้นก่อน · ใช้กี่วัน · ใช้ล่าสุด · เจ้าหน้าที่เห็นแค่ตัวเลข |
| ผู้สมัคร: มาจากไหน · มาแล้วยังไง | การ์ดที่ 6 "ผู้สมัครใหม่" + แท็บ · ช่องทางที่ผู้สมัครเลือกเอง · ถังเดียวกับศูนย์คุมงานสรรหา (ยังไม่มีใครแตะ → มีคนรับ → คิว AI → ติดต่อไม่ได้ / ติดต่อได้ยังไม่นัด / นัดแล้ว) · เวลารอสายแรก · กดชื่อถังไปหน้ารายชื่อถังนั้น |
| ใบที่ยังไม่มีผู้สมัคร: เยอะแค่ไหน นานแค่ไหน | แท็บใหม่ · นับแบบกล่องงาน (เลน) · แยกอายุ 0–3 / 4–7 / 8–14 / 15–30 / 31–90 / เกิน 90 วัน ต่อ BU · ใบค้างนานสุดกดไปเปิดใบได้ |
| มุมเจ้าหน้าที่ (Choice: งานของฉันเป็นหลัก) | งานที่ต้องทำต่อขึ้นบนสุด · ส่วนวิเคราะห์ (กราฟ · แผง BU · แท็บ) พับไว้ กดเปิดเองได้ |
| งานที่ต้องทำต่อ | นับจากเลนกล่องงาน/ถังหน้ารายชื่อ (กดแล้วเจอเลขเท่ากัน): นัดผู้สมัครที่ติดต่อได้ · ส่งประกาศที่มีลิงก์แล้ว · ดันประกาศเงียบ · ปล่อยใบที่ยังต้องหาคน |

ตัวเลขจริงตอนทำ (30 วันล่าสุด · ทุก BU):
- **ผู้สมัคร 91 ใบ** มาจาก Facebook 85 · ไม่ระบุ 6 · มีแต่ LBD · ได้สายแรกเร็ว (ค่ากลาง ~4 นาที)
  - ติดต่อได้ 54 แต่ **นัดแล้ว 0** · ติดต่อไม่ได้ 22 · ยังไม่มีใครแตะ 14 · อยู่ในคิว AI 1
- **ใบเปิด 327** ยังไม่มีผู้สมัครเลย 318 · ค้างเกิน 30 วัน 184 (เกิน 90 วัน 97) · นานสุด 874 วัน (LM)
  - ยังไม่ปล่อยประกาศ 320 · มีลิงก์แล้วรอส่งประกาศ 8 · ปล่อยแล้วเงียบ 3 · ปล่อยแล้วมีคนสมัคร 4
- **บัญชีที่ไม่ได้ใช้ในช่วงนี้ 20 จาก 58**

ยังไม่ทำ (เจ้าของเลือก "ยังไม่ต้อง"): ผู้สมัครออนไลน์ที่ได้เข้าทำงานจริง · ปุ่มส่งออกรายงาน · ความคุ้มค่า
