# แผนรื้อกล่องงานรอบใหม่ — เคาะแล้ว 31 ส.ค. 2569

> เจ้าของ: *"ขอทำหน้ากล่องงานก่อน เพราะตอนนี้ปัญหาหรืออะไรต่าง ๆ มันไม่จบสักที"*
> **ยังไม่ลงมือ — วางแผนอย่างเดียว รอสั่ง** · ลำดับ A→B→C เจ้าของเคาะแล้ว

---

## สิ่งที่เจ้าของเคาะรอบนี้ (31 ส.ค. 2569)

### 1. เส้นเดินของหนึ่งใบ = 3 ขั้น (ยุบจาก 4)

> *"เมื่อเปิดกล่องงานนั้น ๆ ก็จะเจอรายละเอียด เมื่อเราอ่านจบก็กดหน้าถัดไป
> พอไปหน้าถัดไปก็เลือกว่าจะเอาข้อมูลอะไรเพื่อไปโชว์หน้าสาธารณะ
> เลือกเสร็จกดถัดไปก็จะเป็นการพาไป gen link แล้วก็กดส่งขึ้นสาธารณะ"*

```
① อ่านรายละเอียดใบขอ ──ถัดไป──▶ ② เลือกข้อมูลที่จะโชว์หน้าสาธารณะ ──ถัดไป──▶ ③ Gen link + ส่งขึ้นสาธารณะ
```

* **ขั้น ② คือขั้น "ใส่สถานที่" + "เลือกสวัสดิการ" เดิม ยุบเป็นหน้าเดียว** (เจ้าของเคาะเป็น Choice)
  — สถานที่ · สวัสดิการ · รายได้ อยู่ในหน้าเดียวกัน พร้อม**ตัวอย่างประกาศสด**ข้าง ๆ
* ขั้น ② คือ "หน้าตรวจ" จากแผนเดิม (1b) ในตัว: ช่องอันตรายปิดตายไม่มีสวิตช์
  (ชื่อคนออก/เบอร์/ทะเบียน/รหัสภายใน) · **รายได้เลือกได้เฉพาะอัตราจ่าย** อัตราเบิกไม่อยู่ในตัวเลือก

### 2. ไม่มีปุ่ม "ตรวจเสร็จ" — **ปุ่ม "ถัดไป" คือการตรวจ**

แก้ข้อขัดแย้งกับคำสั่ง 27 ส.ค. ("ไม่เอาปุ่มติ๊กว่าทำแล้ว") ไปเลย:
การกด **ถัดไป** จากขั้น ① = ระบบจดเหตุการณ์เงียบ ๆ ว่า *ใครอ่านใบนี้จบ เมื่อไหร่* (ลง audit log)
— เป็นร่องรอยจากการทำงานจริง ไม่ใช่ติ๊กลอย ๆ · ขั้น "ตรวจใบขอ" บนหัวกล่องงานจะมีความหมายจริงครั้งแรก
(เดิมอ่านจากร่องรอยทางอ้อม: มีหมายเหตุ/มีการแก้ข้อมูล)

### 3. ใบที่ไม่เคยเดินเส้นนี้จนจบ = ส่งขึ้นสาธารณะไม่ได้

ทั้งปุ่มรายใบและปุ่มส่งเป็นชุด ⇒ ปุ่มชุดเปลี่ยนความหมายจาก "107 ใบที่ยังต้องหาคน"
เป็น **"N ใบที่ตรวจแล้วพร้อมส่ง"** — ฆ่าความงง 131 vs 107 ในตัว
และเส้นส่งจะถูกพิสูจน์ด้วยการใช้จริงทีละใบก่อนโดยธรรมชาติ (ตอบหนี้ "ปุ่มชุดไม่เคยยิงจริง")

## สามก้อน เรียงตามที่เคาะ

### ก้อน A · จอห้ามโกหก (ทำก่อน — ฐานของทุกอย่าง)

| เรื่อง | ทำอะไร |
|---|---|
| จอมี 3 สภาพ | กำลังโหลด = โครงเปล่า · **พัง = "—" + "อ่านตัวเลขไม่ได้ กดลองใหม่"** · ปกติ = เลขจริง — **ห้ามขึ้น 0 ตอนพังเด็ดขาด** |
| สิทธิ์ไม่ถึง | บอกตรง ๆ "บัญชีคุณไม่มีสิทธิ์เห็นทะเบียนปล่อยประกาศ" — ไม่ใช่โชว์ 0 เหมือนจริง (หนี้ Redteam ข้อ 1) |
| ความช้า 10-60 วิ | เก็บสำเนาใบขอฝั่งเราอายุสั้น + บรรทัด "ข้อมูลเมื่อ X นาทีที่แล้ว" + ปุ่มรีเฟรชดึงสด — เปิดหน้าต้องเร็วกว่าเดิมมาก |
| ปุ่มส่งชุด | ทะเบียนไม่พร้อม = **ปุ่มหาย** ไม่ใช่โผล่พร้อมเลขผิด (หนี้ Redteam ข้อ 2) |
| ตัวเชื่อมข้อมูลตายเงียบ | ⚠️ ปัญหา "โปรเซสอยู่แต่ไม่รับสาย" 3 ครั้ง/2 วันเป็นเรื่องเครื่อง dev — ฝั่งนั้นทำ health check ฟื้นเอง · ส่วนของจริงประเด็นคือ ERP ช้า ซึ่งแคชข้างบนแก้ |

หน้าที่ได้ประโยชน์ร่วม: กล่องงาน · ใบขอ (รายการ) · หน้าหลัก — ใช้ตัวเดียวกัน

### ก้อน B · เส้นเดิน 3 ขั้นใหม่

* รื้อป๊อปไล่งานจาก 4 ขั้นเป็น 3 ขั้นตามบนสุด · ปุ่มเดินหน้าใช้คำว่า **"ถัดไป"** ทุกขั้น
* กดถัดไปจากขั้น ① = จดเหตุการณ์ "อ่านใบนี้จบ" (ใคร/เมื่อไหร่) — แหล่งความจริงของคำว่า "ตรวจแล้ว"
* ขั้น ② เลือกสิ่งที่คนนอกเห็น + ตัวอย่างประกาศสด + ช่องอันตรายปิดตาย + รายได้เฉพาะอัตราจ่าย
* ใบไม่เดินครบ = ส่งไม่ได้ · ปุ่มชุดนับเฉพาะ "ตรวจแล้วพร้อมส่ง"
* 29 ใบที่ประกาศไม่มีที่อยู่ (ผลจากการอุดท่อ) จะโผล่เป็นงานค้างขั้น ② ให้คนเห็นเอง

**ของที่เปลี่ยนตามและต้องตามแก้ให้ครบ (ห้ามหลุด):**

| ของ | กระทบยังไง |
|---|---|
| หัวกล่องงาน "ติดขั้นไหน" | จาก 4 ขั้นเหลือ 3 — เลข 114/13/2/2 เปลี่ยนชุด · เทสต์ "บวกกันลงตัว" ต้องเขียนตาม |
| แถบขั้นบนการ์ด (เพิ่งทำ 31 ส.ค.) | วงเลข 1-4 → 1-3 · % ต่อขั้นเปลี่ยนจาก 25 → 33 · กติกา "ปล่อยแล้ว = 100%" คงเดิม |
| ลิงก์เก่า `?step=` | คีย์ขั้นเปลี่ยน — ลิงก์เดิมต้องไม่พัง (map ค่าเก่า → ขั้นใหม่) |
| ป้าย/นิยามขั้น | แก้ที่แหล่งเดียว (`boardRelease.ts`) — ห้ามพิมพ์ซ้ำตามหน้า |
| editing map | จดรอบใหม่เสมอ |

### ก้อน C · จัดจอให้กล้ากด (ทำท้าย — จัดสวยบนเลขที่นิ่งแล้ว)

* ภาษาปุ่ม 3 ระดับทั้งหน้า: ดูเฉย ๆ (โปร่ง) / บันทึกภายใน (ทึบกลาง) / ออกนอกบ้าน (สีเด่น + ป๊อปยืนยันบอกว่าจะเกิดอะไรกี่ใบ)
* คำอธิบายเลขทุกตัวขึ้นบนจอ ไม่ซ่อนใน tooltip
* แถบลิงก์เงียบยุบเป็นกล่องเดียว "มีใบที่คนยังไม่สมัคร N ใบ กดเข้าไปดู" (สเปคเดิมข้อ 3)
* ใบที่ปล่อยแล้วโชว์ว่า **ใบไหนมีคนสมัครกี่คน / ใบไหนยังเงียบ** (สเปคข้อ 4 — ข้อมูลมีใน ledger แล้ว)
* ตัวกรองย้ายเข้าการ์ดหัว · ทุกคนเห็นปุ่มครบแต่ OPL กดไม่ได้ (สเปคข้อ 2)
* จบแล้ว **ส่งตัวจำลอง Haiku วัดซ้ำ** — เป้า: ใช้ง่ายจาก 4/10 และความมั่นใจกดปุ่มจาก 2/10 ต้องขยับชัด
