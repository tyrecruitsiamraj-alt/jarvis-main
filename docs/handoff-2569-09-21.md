0. **ใบขอชั่วคราวบันทึกผู้รับผิดชอบ/หมายเหตุไม่ได้** — ใบชั่วคราวอยู่คนละตาราง
   (`st_prequest_head`) และ id มี prefix `siamraj-pre:` แต่หน้ารายละเอียดส่ง **เลขเปล่า**
   ⇒ ไปหาในตารางใบขอจริง ⇒ ไม่เจอ ⇒ 404 "ไม่พบใบขอ" ⇒ **บันทึกไม่ได้เลยสักใบ**
   แก้แล้ว: หาในตารางใบจริงก่อน ไม่เจอค่อยถอยไปหาที่ตารางใบชั่วคราว
   \+ หน้าจอเดิมขึ้น error เป็น **สีเทาตัวเล็กเหมือนตอนสำเร็จ** ⇒ คนคิดว่าบันทึกแล้ว
   (ช่องยังโชว์ค่าที่พิมพ์เพราะเป็น state ในจอ) แล้วมาเจอทีหลังว่าหาย — เปลี่ยนเป็นแดง + ✓/🔴
