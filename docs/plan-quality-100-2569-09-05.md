# แผนดันคะแนนใช้งาน 63/62 → สูงสุด (5 ก.ย. 2569)

> จัดทำโดย Fable (สมอง — วางแผนอย่างเดียว **ไม่แตะโค้ด**) · งานลงมือทั้งหมดส่ง subagent
> ฐานข้อมูล: ผลทดสอบ Haiku สวมบทพนักงานใหม่ 2 รอบ (PC 63/100 · มือถือ 62/100)
> + บั๊กที่ตรวจยืนยันบนจอจริงแล้ว

## หลักการมอบงาน (ตามโปรโตคอลเจ้าของ)
- **Fable** = วางแผน · เขียนสเปก/คำ · รีวิวผลงาน · ตัดสินใจ — ห้ามแตะโค้ด
- **Opus** = งานที่ต้องคิด (ออกแบบ pattern · ไล่เรื่องความเร็ว · รื้อหน้า)
- **Sonnet** = งานตามสั่งซ้ำ ๆ ตามสเปกชัด (แทนคำตามตาราง · ใส่ empty state ตามข้อความที่ให้)
- **Haiku** = ผู้ทดสอบตาใหม่ ให้คะแนนซ้ำหลังจบแต่ละ wave
- ทุก wave: จบแล้วรันเทสต์เต็ม + ดูจอจริง (PC/มือถือ) + push แยก commit (ถอยได้ทีละ wave)
- ของที่กระทบหน้าตา staff อยู่หลังสวิตช์ `?ui=v2` ตามเดิม · แก้คำ = แก้ที่แหล่งเดียว
  (metricDictionary / lumosQueueDefs / followSchedule) แล้วอัปเดตเทสต์ตามกติกาโปรเจกต์

## เป้าหมายที่สัญญาได้จริง
คะแนนจากผู้ทดสอบตาใหม่เป็นอัตวิสัย — **100 เป๊ะสัญญาไม่ได้** สิ่งที่วัดได้และจะทำให้ถึง:
- Wave 1 จบ: ไม่มีหน้าไหนต่ำกว่า 6 · รวม ≥ 75
- Wave 2 จบ: ไม่มีหน้าไหนต่ำกว่า 7 · รวม ≥ 85
- Wave 3 จบ: ทุกหน้า ≥ 8 · รวม ≥ 90 · ไม่มีบั๊ก navigation/จอพังเหลือ

## Wave 1 — คำศัพท์ + ป้ายว่าง + ปุ่มบอกผล (เร็ว ได้แต้มเยอะ)

- ตรวจรับ: Fable เทียบจอก่อน-หลังทุกจุด + เทสต์เต็มผ่าน

### 1.2 หน้าว่างต้องบอกทางต่อ (ดูแลหลังเริ่มงานได้ 4/10 เพราะว่างเปล่า)
- ทุกหน้า/ทุกกล่องที่เป็น 0: บอก 3 อย่าง — นี่คืออะไร · ทำไมว่าง · ปุ่มไปเริ่มที่ไหน
- ผู้ทำ: **Sonnet** (Fable เขียนข้อความให้ครบทุกจุดก่อน)

### 1.3 หน้าสาธารณะบนมือถือ: ปุ่ม "สมัครงาน" ต้องเห็นโดยไม่ต้องเลื่อนหา
- การ์ดงานบนมือถือให้ปุ่มสมัครโผล่ในจอแรกของการ์ด
- ผู้ทำ: **Sonnet**

## Wave 2 — มือถือ + หน้าที่คะแนนต่ำสุด

### 2.1 ติดตาม (5/10 — แย่สุด)
- การ์ด 3 คอลัมน์บนจอ 375px → เรียงตั้ง 1 คอลัมน์ · คำอธิบายยาวย้ายไปหลังไอคอน (?)
- ปฏิทิน: แถบคำอธิบายสัญลักษณ์ (legend) ตัวเล็ก 11px → โตขึ้น + พับได้บนมือถือ
- ผู้ทำ: **Opus** (หน้านี้ตรรกะแน่น เพิ่งรื้อรอบ ก.ย. — ต้องไม่แตะตรรกะ)
### 2.2 จับคู่งาน (6/10): 16 ช่องบนมือถือ → กลุ่มละแถว พับ/คลี่ได้ (ตัวเลขอยู่ครบ)
- ผู้ทำ: **Opus**
### 2.3 Dashboard บนมือถือ (5/10): หัวไทย (จาก 1.1) + โครง 2 คอลัมน์ → 1 คอลัมน์ + โครงกระดูกตอนโหลด
- ผู้ทำ: **Sonnet** ตามสเปก Fable

## Wave 3 — ความเร็วครั้งแรก + ย้อนกลับให้ครบระบบ

### 3.1 โหลดครั้งแรกช้า (วัดจริงตอน cache เย็น: flow-summary 4.4s · unit-requests 8.2s/703KB)
- อุ่น cache อัตโนมัติหลัง API ตื่น + ตอบของเก่าก่อนแล้วเติมของใหม่ (stale-while-revalidate)
- ลดขนาดคำตอบ unit-requests (703KB — ส่งเฉพาะฟิลด์ที่จอใช้)
- ผู้ทำ: **Opus** (แตะชั้นข้อมูล ต้องคิด) · ห้ามเปลี่ยนนิยามตัวเลข
### 3.2 ป๊อปอัปที่เหลือทั้งระบบผูกปุ่มย้อนกลับ (แบบเดียวกับฟอร์มสมัครที่แก้แล้ว)
- ใช้ hook `useCloseOnBack` เดิม · **ยกเว้น** ป๊อปอัปที่ผูก URL อยู่แล้ว (?jobId=)
- ผู้ทำ: **Sonnet** ตาม checklist ที่ Opus สำรวจก่อน
### 3.3 JobListPage/Matching เปิด-ปิดรายละเอียดกับประวัติ (push ตอนเปิด ให้ back = ปิด)
- ผู้ทำ: **Opus** (semantics ประวัติ ต้องคิดเคสพิมพ์ค้นหา)
