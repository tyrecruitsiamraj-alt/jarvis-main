# คำถามของผู้บริหารต่อหน้าภาพรวมงานสรรหา (20 พ.ย. 2569)

เจ้าของจำลองผู้บริหารที่อยากรู้ทุกอย่าง แล้วถามว่าหน้าภาพรวมตอบได้ไหม ถ้าจอตอบไม่ได้ ผู้ช่วย AI ต้องช่วยได้
รายการนี้ใช้เป็นชุดทดสอบ: ของก้อนสาม (ผู้ช่วย AI) ต้องถามทีละข้อบนเว็บจริงแล้วเทียบกับเลขบนจอ

แท็บ "Scale ลง" = แท็บที่ 3 ของหน้าภาพรวม (`ov=scale` · เห็นเฉพาะ Admin จนกว่าเจ้าของเคาะ)
ตัวคิด `src/lib/overviewScale.ts` · จอ `src/components/dashboard-trends/v2/ScalePanel.tsx`

## ก้อนสอง + ก้อนสาม (21 พ.ย. 2569) — ตอบเพิ่มได้ที่ไหน

| เรื่อง | ตอบที่ไหน |
|---|---|
| คนที่ได้ตรงเกณฑ์ใบขอไหม | แถว ตรงเกณฑ์ใบขอ ทุกชั้น + ตารางไล่ตามขั้น · เทียบพื้นที่ไม่ได้บอกเหตุ 4 แบบ |
| เพิ่มหรือลดจากช่วงก่อน | ทุกกล่อง (ชั้นวัน = เทียบวันก่อน) · กดกล่อง = เทียบทีละ BU / คน · แถวที่หายไปขึ้นเป็น 0 |
| เดือนนี้เทียบเดือนก่อน | ตารางเทียบเดือน (เลือกช่วงหลายเดือน) กดเดือน = กราฟรายวันของเดือนนั้น |
| ใบที่ปิดได้ ปิดเพราะทำอะไร | กล่อง หาได้แล้ว (ชั้น BU) → รายใบ: งานที่ทำ · รายชื่อ · นัดได้ · มา → กดเลขที่ใบ = ไล่ตามวัน |
| ใบที่ยกเลิก ทำอะไรไปแล้ว · ยกเลิกเพราะอะไร | กล่อง ยกเลิก → ยกเลิกเพราะอะไร (รวมกัน = กล่อง) + รายใบพร้อมเหตุผล |
| ตั้งแต่ขอถึงวันนี้ ใครทำอะไรวันไหน | กดเลขที่ใบขอในรายใบ → ขอมา · ประกาศ · Gen link · โพสต์แล้ว · Autopost · Scrap · รายชื่อเข้า · AI โทรแล้ว · ลงผลติดต่อ · ลงผลนัด · หาได้แล้ว · ยกเลิก |
| รายชื่อไปไหนต่อ หลุดตรงไหน | กดกล่องรายชื่อ → "ไปไหนต่อ" (ช่องรวมกัน = กล่อง) + เหตุผลที่ติดต่อไม่ได้ / นัดไม่สำเร็จ |
| แจ้งเข้าใช้กี่วัน มาจากช่องทางไหน | กดกล่อง แจ้งเข้า → กรอกใบ · แจ้งเข้า · ใช้กี่วัน (แจ้งเข้าก่อนกรอกใบบอกตรง ๆ) |
| ใครไม่ทำอะไร หายไปกี่วัน | ตาราง แยกตามคน: คนที่มีงานใน 60 วันล่าสุดแต่ช่วงนี้ไม่มี ขึ้นแถวด้วยงาน 0 + "ไม่มีงานมา N วัน" |
| ผู้ช่วย AI | `/api/exec-summary` (เลขชุดเดียวกับแท็บ) + `/api/request-timeline` — ต้องถามจริงบนเว็บแล้วเทียบกับจอทีละข้อ ก่อนจะบอกว่าตอบได้ |

## ที่ยังตอบไม่ได้

- นัดแล้วไม่มา **เพราะอะไร** — ผลนัด (มา / ไม่มา / เลื่อนนัด) ไม่มีช่องเหตุผลในระบบ
- คนที่สมัครใบที่ปิดไปแล้วหรือใบขอชั่วคราว ตรงเกณฑ์ไหม — ใบพวกนี้ไม่อยู่ในสำเนาใบขอ จึงไม่มีเกณฑ์ให้เทียบ (ขึ้นในกล่อง เทียบพื้นที่ไม่ได้ › ไม่มีรายละเอียดใบขอ)

## ข้อที่เจ้าของเคาะ

- แจ้งเข้า **คงเดิม** (นับทุกใบแจ้งเข้าตั้งแต่ต้นปี จับคู่ด้วยเบอร์) — ไม่แยกก่อน/หลังวันกรอกใบ
- ทำเป็นอีกแท็บ ไม่แตะแท็บเดิม เจ้าของเปิดดูแล้วเลือกเองว่าจะเก็บอันไหน
- คำบนจอต้องเป็นคำที่คนพูด
