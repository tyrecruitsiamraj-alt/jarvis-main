# iRecruit หน้าเพิ่มผู้สมัคร (applicants/create) — แผนที่ช่อง

สำรวจ 14 ต.ค. 2569 ในเบราว์เซอร์ที่เจ้าของล็อกอินให้ อ่านอย่างเดียว ดักการบันทึกทุกเส้นไว้ตลอด
ใช้กับงานแท็บตรวจเอกสาร (ผู้สมัครส่งรูปบัตร → HR ตรวจ → กด "นำเข้า" → กรอกหน้านี้ให้)

## ช่องทางบันทึก
- ไม่มี API สาธารณะ หน้าเว็บส่งฟอร์ม `multipart` ไปที่ `POST /applicants` ด้วย AJAX (`X-Requested-With`) ใช้ session ของคนที่ล็อกอิน + `_token` (CSRF)
  ตอบ JSON `{ ok, redirect, message }` · สำเร็จแล้วหน้าเด้งไป `res.redirect`
- เส้นช่วยของหน้า (อ่านอย่างเดียว แต่เป็น POST):
  `applicants/checks/id-card` (เคยสมัครไหม) · `applicants/checks/blacklist` · `applicants/address/amphur` · `applicants/address/tambon` · `applicants/job-descriptions`
- หน้ารับ `?register_id=<uuid>` จาก URL ใส่ช่องซ่อน `register_id` (`getFromRecruit()` ใน `register.js`) ต้องถามทีม iRecruit ว่ารับข้อมูลจากที่ไหน

## ช่องจากบัตรประชาชน (ทุกช่องหาได้ด้วย id)
| ข้อมูล | id / name | หมายเหตุ |
|---|---|---|
| เลขบัตร | `id_card` | เปลี่ยนค่าแล้วหน้ายิง id-card check เอง |
| คำนำหน้า | `pfix_code` (select) | ค่ามีช่องว่างท้าย: `03 `=นาย `04 `=นางสาว `05 `=นาง `01 `=ดช. `02 `=ดญ. (34 ตัวเลือก รวมยศ) |
| ชื่อ / นามสกุล | `fname` / `lname` | ไทยเท่านั้น |
| Firstname / Lastname | `fname_eng` / `lname_eng` | อังกฤษเท่านั้น |
| เพศ | `sex` (ข้อความ) | หน้าเติมเองจากคำนำหน้า 5 ตัวบน · ยศ/คุณ ต้องกรอกเอง |
| วันเกิด | `birth_date` | `dd/mm/yyyy` **ปี ค.ศ.** (บัตรเป็น พ.ศ. ต้องลบ 543) |
| อายุ | `age` | อ่านอย่างเดียว หน้าคิดจากวันเกิดเอง |
| บ้านเลขที่ / หมู่ / ซอย / ถนน | `census_address` / `census_number` / `soi` / `road` | หมู่ บังคับ |
| จังหวัด | `census_province` (select) | |
| เขต/อำเภอ | `getAmphur` (select ไม่มี name) → ช่องซ่อน `census_amphur` | โหลดหลังเลือกจังหวัด |
| แขวง/ตำบล | `getTumbon` (select ไม่มี name) → ช่องซ่อน `census_tumbon` | โหลดหลังเลือกอำเภอ |
| วันออกบัตร | `id_issued` | `dd/mm/yyyy` |
| วันบัตรหมดอายุ | `id_exprired` (สะกดตามระบบ) | บัตรตลอดชีพ = ติ๊ก `is_longlife2` แล้วช่องนี้ปิด |

## ใบขับขี่
แถวละชนิด: ชนิด 1–4 (`type01`–`type04`) · รถสาธารณะ (`type05`) · รถจักรยานยนต์ (`type09`)
- วันหมดอายุ = `adate01` … `adate09`
- กล่องติ๊ก `typeXX` = **ตลอดชีพ** (ติ๊กแล้วช่องวันหมดอายุล็อก + ช่องซ่อน `type[]` เป็น `Y`) ไม่ใช่ "มีใบชนิดนี้"
- ต้องคลิกจริง (`click()`) ช่องซ่อนถึงเปลี่ยน · ตั้ง `checked` เฉย ๆ ไม่พอ

## เอกสารการสมัคร
`yes1`…`yes8` / `no1`…`no8` (ครบ / ไม่ครบ): 1 รูปถ่าย · 2 สำเนาบัตรประชาชน · 3 ทะเบียนบ้าน · 4 ใบขับขี่ · 5 วุฒิการศึกษา · 6 ใบผ่านเกณฑ์ทหาร · 7 ใบผ่านงาน · 8 ใบเปลี่ยนชื่อ-นามสกุล

## ช่องอื่นที่บังคับ (ไม่ได้มาจากบัตร)
`division_code` แผนก (BS CR CT DB DS FL IO LA LB LM OUS PE PS SB SN) · `staff_title` (516 พนักงาน / 515 เจ้าหน้าที่) ·
`description1` ลักษณะงาน (571 ตัวเลือก) · `replace_type` (IN / WI / EX)

## ผลทดสอบกรอกอย่างเดียว (ข้อมูลจำลอง ไม่บันทึก)
คำนำหน้า → เพศขึ้นเอง ✔ · วันเกิด → อายุคิดเอง ✔ · จังหวัด → อำเภอ → ตำบล + รหัสซ่อน ✔ · ใบขับขี่ตลอดชีพ + วันหมดอายุ ✔ · เอกสารครบ/ไม่ครบ ✔
ไม่มีคำขอไป `POST /applicants` · โหลดหน้าใหม่ล้างค่าแล้ว
