## 🏠 หน้าหลัก
เห็นภาพรวมงานวันนี้ทันทีที่เปิด — งานด่วนมีกี่ใบ ค้างกี่ใบ ใครรับผิดชอบอะไร

## 🏢 หน่วยงาน (ใบขอจาก ERP)
- ดึงใบขอจาก ERP มาให้เอง **เฉพาะใบที่ยังหาคนไม่ครบ** ไม่ต้องไปเปิด ERP ดู
- เห็นครบ: ขอมากี่คน หาได้แล้วกี่คน เหลือกี่คน ใครส่งใบ เงินเดือน สถานที่ปฏิบัติงาน สัญชาติเจ้านาย
- ชิปสีบอกอายุใบขอ — ใบไหนดองนานเกินเห็นชัดทันที
- จดหมายเหตุ ตั้งผู้รับผิดชอบ (สรรหา/คัดสรร/OPL) บันทึกสถานะทำงาน — เก็บฝั่งเรา ไม่ยุ่งกับ ERP
- แต่ละคนเห็นเฉพาะใบของแผนกตัวเอง

## 🔍 Matching — หัวใจของระบบ
- เปิดใบขอ → **AI คัดคนของเราที่เหมาะกับงานให้เลย** เรียงตามเกณฑ์ที่เจ้าของกำหนด
  (อายุ → ที่อยู่ → ประสบการณ์ → เหล้า-บุหรี่ → คดี → รายได้)
- คนของเราไม่พอ → กดค้นฐาน iRecruit ต่อได้ในหน้าเดียวกัน
- แต่ละคนมีป้ายบอกว่าตรงเกณฑ์ข้อไหน ไม่ตรงข้อไหน เพราะอะไร
- บันทึกผลคัดกรอง เหล้า-บุหรี่/ประวัติคดี ได้ทั้งคนของเราและคน iRecruit
- เจอคนที่ใช่แล้วเลือกได้ 3 ทาง:
  - **โทรเอง** — แตะเบอร์ = จองสิทธิ์โทรอัตโนมัติ คนอื่นและ AI จะไม่โทรทับ
  - **ส่ง AI โทร** — ติ๊กเลือกแล้วส่ง ระบบโทรสัมภาษณ์ให้
  - **ตั้งชุดรออนุมัติ** — ยังไม่โทรจนกว่าหัวหน้าจะกดอนุมัติ
- คนเดียวติดใบขออื่นอยู่ → ขึ้นป้าย "ติดใบขอ" กันเสนอซ้ำซ้อน

## 🤖 ระบบโทรอัตโนมัติ (Lumos) — สร้างครบวงแล้ว แต่ยังปิดอยู่
- โทรเสร็จระบบตัดสินใจต่อเอง:
  - **สนใจ** → ปิดเรื่อง ส่งต่อเจ้าหน้าที่
  - **ไม่เอางานนี้** → ปิดแค่ใบนี้ ใบอื่นยังเสนอได้
  - **เลิกหางานแล้ว** → หยุดโทร 30 วัน ทุกใบ
  - **ไม่รับสาย** → โทรซ้ำเอง สูงสุด 3 ครั้ง เว้น 24 ชม.
  - **ขอเลื่อน** → นัดใหม่ตามเวลาที่บอก (ไม่บอก = +4 ชม.)
- โทรไม่สำเร็จจนครบเพดาน → ตกถัง **"ต้องคนตาม"** ไม่มีงานหายเงียบ
- ห้ามโทรช่วง 20:00–08:00
- มี 3 โหมดสลับได้ที่ Settings ไม่ต้องแก้โปรแกรม:
  **manual** (คนสั่งทุกครั้ง — ค่าปัจจุบัน) / **assist** (ระบบจัดรายชื่อ คนกดอนุมัติ) / **auto** (ระบบทำเองหมด)
- อนุมัติแล้วมี **10 นาทีให้เปลี่ยนใจ** ถอนคน/ยกเลิกได้ก่อนโทรจริง

## 📞 งานโทร (ตอนนี้เห็นเฉพาะแอดมิน — ซ่อนไว้ตามคำสั่งเจ้าของ)
- **ครึ่งบน "โทรของฉัน"** — งานโทรที่รับมาทั้งหมด เรียงให้ว่าโทรใครก่อน กดผลแล้วระบบพางานไปต่อเอง
- **ครึ่งล่าง "ภาระทีม"** — หัวหน้าเห็นว่าใครถืองานกี่สาย ใครดองงาน โอนงาน/คืน AI/เทกองคนลาป่วยได้

## 📋 Follow — ห้องบังคับการ
- **กรวยการโทรทั้งระบบ**: ส่งไปกี่คน → โทรติดกี่ → สนใจกี่ → ไม่รับกี่ → ต้องคนตามกี่
- ผลจาก AI กับผลจากคนโทรเอง **นับรวมกันในตัวเลขเดียว**
- ถัง "ต้องคนตาม" — กด "รับไปตาม" แล้วไปโทรต่อได้เลย ไม่มีทางที่สองคนรับคนเดียวกัน
- ชุดส่งที่รออนุมัติโผล่ที่นี่ พร้อมปุ่มอนุมัติ/ยกเลิก และตัวนับถอยหลังช่วงเปลี่ยนใจ

## 📊 Dashboard
- สมการงานค้าง: **ค้างเดิม + ขอใหม่ − หาได้ − ยกเลิก = เหลือหา** เห็นทุกเดือน
- ใบไหนเสี่ยงเกินกำหนด ไซต์ไหนงานหนักสุด แนวโน้มใบขอเข้าใหม่ พยากรณ์ล่วงหน้า
- กดทุกตัวเลขเพื่อดูรายใบได้

## 👥 ผู้สมัคร · 🌐 บอร์ดรับสมัครสาธารณะ
- ประวัติผู้สมัครรายคน: สัมภาษณ์กี่ครั้ง ไป/ไม่ไป เคยลงงานที่ไหน
- คนนอกเปิดดูตำแหน่งว่างและสมัครเองได้ผ่านลิงก์ ใบสมัครวิ่งเข้าระบบเอง

## ⚙️ Settings (แอดมิน)
- สวิตช์โหมดโทร manual/assist/auto แยกรายจุด · จัดการสถานะทำงาน · สิทธิ์ผู้ใช้
- ล็อกอินด้วยบัญชี Microsoft ของบริษัท
