# กติกา SLA

## จำนวนวัน SLA ตามประเภทความเร่ง

**ค่ากลางของระบบ** (ใช้กับใบที่ไม่ได้ตั้งเกณฑ์เอง):

* **ฉุกเฉินย้อนหลัง** (retroactive) — 7 วัน นับจากวันที่ยื่นใบขอ
* **ฉุกเฉิน** (urgent) — 15 วัน นับจากวันที่ต้องการคน
* **ล่วงหน้า** (advance) — 15 วัน นับจากวันที่ต้องการคน

**เส้นแบ่งประเภท** — ห่างจากวันที่กรอกถึงวันที่ต้องการ **น้อยกว่า 7 วัน = ฉุกเฉิน**
· 7 วันขึ้นไป = ล่วงหน้า · วันที่ต้องการอยู่ก่อนวันที่กรอก = ฉุกเฉิน/ย้อนหลัง

## เกณฑ์เฉพาะใบ (10 ก.ย. 2569)

เจ้าของสั่ง: *"หลักเกณฑ์ ฉุกเฉิน / ฉุกเฉิน-ย้อนหลัง / ล่วงหน้า ทำให้ Set เป็นใบไว้หน่อย
เพราะบางใบใช้คำนวณไม่เหมือนกัน แต่ถ้าไม่ Set ก็เอาของเดิมเป็น Default แก้ก็แก้ที่หน้าใบขอ"*

ตั้งได้ **4 ตัวเลขต่อใบ** ที่หน้าใบขอ — เส้นแบ่ง + จำนวนวันให้หาคนแยก 3 ประเภท
**ช่องไหนไม่กรอก = ใช้ค่ากลางของช่องนั้น** (ไม่ใช่ 0)

* ค่าที่ตั้งมีผล **ทุกที่ทั้งระบบ** — หน้าใบขอ · รายการใบขอ · แดชบอร์ด SLA · กราฟแยกประเภท
* เก็บที่ `siamraj_unit_notes.field_overrides.lead_rules` (คีย์ = เลขที่ใบขอ**ดิบ**)
* 🔴 **ประเภทย้อนหลังไม่ขึ้นกับเส้นแบ่ง** — วันที่ต้องการอยู่ก่อนวันที่กรอกคือย้อนหลังเสมอ
* 🔴 **ให้เวลาหาคน 0 วันตั้งไม่ได้** (ครบกำหนดตั้งแต่วันแรก = ใบหลุด SLA ทั้งกอง) ·
  เส้นแบ่ง 0 วันตั้งได้ แปลว่าไม่มีช่วงล่วงหน้า
* ค่าที่คำนวณไม่ได้ (ติดลบ · เกิน 365 · ไม่ใช่ตัวเลข) ถูกตัดทิ้งแล้ว**ตกไปใช้ค่ากลาง**

**นิยามอยู่ที่ `src/lib/requestLeadKind.ts` ที่เดียว** — ห้ามหน้าไหนหรือฝั่ง API ไหน
เขียนเลข 7/15 เองอีก

## SLA มี 3 แบบ

**1. SLA การหาได้ (Fulfillment SLA)**
วัดว่าหาคนได้กี่อัตราภายในกำหนด

**2. SLA การปิดครบใบขอ (Full Closure SLA)** ← **ตัวหลักที่ผู้บริหารดู**
วัดว่าทั้งใบขอหาได้ครบภายในกำหนดหรือไม่

**3. SLA การจบงาน (Resolution SLA)**
วัดว่าใบขอไม่เหลืออัตราต้องหาแล้วหรือยัง ไม่ว่าจะเพราะหาได้ครบหรือถูกยกเลิก

> ⚠️ **สำคัญ: อัตราที่ถูกยกเลิก ห้ามนับเป็นปิดครบใบขอ**

## สถานะ SLA

* `on_track` — ทันกำหนด
* `at_risk` — เสี่ยงเกิน
* `breached` — เกินแล้ว
* `fulfilled_on_time` — หาได้ทันกำหนด
* `fully_closed_on_time` — ปิดครบทันกำหนด
* `resolved_on_time` — จบงานทันกำหนด
* `closed_late` — ปิดช้ากว่ากำหนด
* `resolved_late` — จบงานช้ากว่ากำหนด

## เกณฑ์ตัดสิน

**เสี่ยงเกิน (at_risk):** ยังไม่เกินกำหนด และเหลือเวลา 0–3 วัน

**เกินแล้ว (breached):** วันนี้เลยวันครบกำหนดแล้ว และใบขอยังไม่ปิดครบ/ยังไม่จบงาน
(ขึ้นกับว่าวัด SLA แบบไหน)
