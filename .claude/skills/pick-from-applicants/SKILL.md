# เลือกคนที่สมัครแล้ว → ส่งลงงาน

โคลนวิธีคิดของคนที่เลือกแล้ว **"อยู่ยาว"** ไม่ใช่แค่ "ผ่านเกณฑ์"

## หลักที่คนเก่งใช้

**คนทั่วไป:** ดูว่าใครคะแนนสูงสุด → จองตัวคนนั้น
**คนเก่ง:** ดูว่า **ใครจะไม่ลาออกใน 3 เดือนแรก** → เพราะได้คนแล้วออก = เสียเวลาสองรอบ
กับเสียเครดิตกับหน่วยงานด้วย

## ขั้นตอน

### 1. ดูข้อมูลที่ระบบมีให้แล้ว

* คะแนนแมทและเหตุผลที่ AI ให้ (การ์ดผู้สมัครในหน้า Matching)
* ป้ายเกณฑ์รายข้อ: อายุ · ที่อยู่ · ประสบการณ์ · เพศ · รายได้
* ผลคัดกรอง เหล้า-บุหรี่ / ประวัติคดี (ถ้าเจ้าหน้าที่บันทึกไว้)
* **ประวัติการติดต่อ** — เคยถูกโทรหากี่ครั้ง ตอบว่าอะไร (แถบในการ์ดผู้สมัคร)
* ป้าย "ติดใบขอ" — คนนี้กำลังถูกเสนอที่ใบอื่นอยู่

### 2. สัญญาณว่าจะอยู่ยาว (เรียงตามน้ำหนักจริง)

| สัญญาณ | อ่านว่าอะไร |
|---|---|
| **บ้านใกล้ที่ทำงานจริง** | ตัวทำนายการอยู่ยาวที่แรงที่สุด — ไกลแล้วเหนื่อยเดินทาง ออกใน 1–2 เดือน |
| เคยทำงานลักษณะเดียวกันมาก่อน | รู้ว่างานจริงเป็นยังไง ไม่ช็อกแล้วออก |
| อยู่ที่เดิมนาน (ดูประวัติงาน) | คนเปลี่ยนงานถี่มักเปลี่ยนอีก |
| รายได้ที่ขอ ≤ ที่ใบขอให้ | ขอสูงกว่าที่ให้ = รับไปก่อนแล้วหางานใหม่ต่อ |
| รับสายเร็ว ตอบชัดเจน | สนใจงานจริง ไม่ใช่หว่านใบสมัคร |

### 3. ธงแดง — เจอแล้วต้องคิดหนัก

* **เคยปฏิเสธงานลักษณะเดียวกันมาก่อน** (ดูประวัติการติดต่อ) — เสนอซ้ำมักได้คำตอบเดิม
* ติดใบขออื่นอยู่แล้วในสถานะจองตัว/ลงงาน — เสนอซ้อนแล้วจะแย่งกันเอง
* บ้านไกลมากแต่ยอมรับทุกอย่าง — มักเป็นการรับไปก่อน
* ประวัติคดี = มี → ดูรายละเอียดก่อนตัดสิน **อย่าตัดอัตโนมัติ**
  (ระบบตั้งใจไม่เอาความหนักเบาของคดีมาคิดคะแนนเอง)

### 4. ลำดับสถานะที่ถูกต้อง

```
ติดต่อแล้ว → จองตัว → ลงงาน
```

* **ติดต่อแล้ว** = คุยแล้ว เขาสนใจ แต่ยังไม่ตกลง
* **จองตัว** = ตกลงกันแล้ว กันคนไว้ให้ใบนี้ — คนอื่นจะเห็นป้าย "ติดใบขอ"
* **ลงงาน** = เริ่มงานจริงแล้ว

> ⚠️ อย่าข้ามไป "ลงงาน" ทั้งที่ยังไม่เริ่มงานจริง — ตัวเลข "หาได้แล้ว"
> บนแดชบอร์ดจะเพี้ยน และไปชนกับยอดทางการจาก ERP

### 5. สรุปให้ตัดสินใจได้

```
แนะนำ: [ชื่อ] — เพราะ [เหตุผลที่ทำนายว่าอยู่ยาว 2-3 ข้อ]
สำรอง: [ชื่อ] — ต่างกันตรง …
ไม่แนะนำรอบนี้: [ชื่อ] — เพราะ [ธงแดง]
ก่อนจองตัวควรถามเพิ่ม: …
```

## ⚠️ ยังต้องถอดวิชาเพิ่มจากคนจริง

ข้อ 2 กับ 3 เขียนจากรูปแบบที่เห็นในข้อมูลระบบ **ยังไม่ได้ยืนยันกับสถิติจริง**
ควรเก็บเพิ่มด้วยการดูคนที่ลงงานแล้วอยู่เกิน 6 เดือน เทียบกับคนที่ออกก่อน 3 เดือน
แล้วดูว่าต่างกันตรงไหนจริง ๆ — แล้วเอามาแก้น้ำหนักในตาราง
