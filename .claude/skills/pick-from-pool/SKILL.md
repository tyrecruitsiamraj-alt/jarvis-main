# หาคนจากฐาน (คนที่ยังไม่ได้สมัครงานนี้)

โคลนวิธีคิดของคนที่ **"ใบไหนไม่มีคนสมัคร ก็ยังหาคนได้"**
งานนี้ยากกว่าเลือกจากคนที่สมัครมา เพราะต้องตัดสินใจว่า **จะยอมหย่อนตรงไหน**

## หลักที่คนเก่งใช้

**คนทั่วไป:** ค้นตามสเปค → ไม่เจอ → บอกหน่วยงานว่าหาไม่ได้
**คนเก่ง:** ไม่เจอ → **รู้ว่าควรผ่อนเกณฑ์ไหนก่อน** และผ่อนแล้วเสี่ยงอะไร
→ เสนอทางเลือกพร้อมผลกระทบ ไม่ใช่ยอมแพ้

## ลำดับการผ่อนเกณฑ์ (สำคัญที่สุดของ skill นี้)

ผ่อนจากที่**เสียหายน้อยสุด**ไปหามากสุด:

| ลำดับ | ผ่อนอะไร | เสี่ยงอะไร |
|---|---|---|
| 1 | **รายได้ที่ขอ** (สูงกว่าที่ให้เล็กน้อย) | ต่อรองได้บ่อย · เสี่ยงต่ำสุด ลองก่อนเสมอ |
| 2 | **ประสบการณ์ตรง** → เอาสายใกล้เคียง | ต้องสอนงานเพิ่ม · แต่คนขยันเรียนรู้ได้ |
| 3 | **ช่วงอายุ** (ขยายบน/ล่างนิดหน่อย) | ต้องดูหน้างานว่าใช้แรงไหม |
| 4 | **พื้นที่** (อำเภอ → จังหวัด → จังหวัดติดกัน) | **เสี่ยงสูงสุด — ระยะทางคือตัวทำให้ลาออกอันดับหนึ่ง** ผ่อนท้ายสุด |

> ⚠️ **อายุกับพื้นที่เป็น "เกณฑ์แข็ง" ในระบบ** (`candidatePriority.ts` → `hard: ['age','area']`)
> ผ่อนได้แต่ต้องบอกเจ้าของงานทุกครั้ง ห้ามผ่อนเงียบ ๆ

## ขั้นตอน

### 1. ดูก่อนว่าทำไมไม่เจอ

* **ไม่มีคนในพื้นที่เลย** → ผ่อนพื้นที่ หรือคุยเรื่องที่พัก/ค่าเดินทาง
* **มีคนแต่สกิลไม่ตรง** → ดูตำแหน่งใกล้เคียงในกลุ่มงานเดียวกัน
* **มีคนตรงแต่ติดใบขออื่นหมด** → คุยลำดับความสำคัญกับหัวหน้า อย่าแย่งกันเอง
* **รายได้ต่ำกว่าตลาด** → ปัญหาอยู่ที่ใบขอ ไม่ใช่ที่การค้นหา — ต้องคุยกับหน่วยงาน

### 2. ช่องทางหาคน เรียงตามที่ควรลองก่อน

1. **คนของเรา** (บอร์ด) — คนที่ผ่านสัมภาษณ์แล้วรอลงงาน ได้เร็วที่สุด
2. **ฐาน iRecruit** — คนที่เคยสมัครกับบริษัท ปลุกกลับมาได้
3. **ส่งทีมคอนเทนต์** — ให้ทำโพสประกาศใหม่ (ช้ากว่า แต่ได้คนใหม่)
4. **Scraping** — ดึงจากแหล่งภายนอก

### 3. เช็กก่อนเสนอ — ห้ามพลาด

* คนนี้ **ถูกพักเบอร์อยู่ไหม** (บอกว่าเลิกหางานแล้ว = พัก 30 วัน · เบอร์ผิด = 7 วัน)
  → ระบบกันให้อัตโนมัติที่ `insertQueueItems()` แต่ถ้าเสนอด้วยมือต้องดูเอง
* **เคยถูกโทรหาไปแล้วกี่ครั้ง** — ดูแถบประวัติการติดต่อในการ์ด
  โทรซ้ำคนเดิมบ่อยเกินจะเสียความสัมพันธ์
* **ติดใบขออื่นอยู่ไหม** — ป้ายม่วง "ติดใบขอ"

### 4. สรุปเป็นทางเลือกให้ตัดสินใจ ไม่ใช่คำตอบเดียว

```
ใบขอนี้หาคนตรงสเปคไม่ได้ เพราะ [เหตุผลจริง]

ทางเลือก
A. ผ่อน [เกณฑ์] จาก … เป็น … → ได้เพิ่มประมาณ n คน · เสี่ยง …
B. ขยายไปตำแหน่งใกล้เคียง [ชื่อ] → ได้เพิ่มประมาณ n คน · ต้องสอนงาน …
C. ส่งทีมคอนเทนต์ทำประกาศใหม่ → ใช้เวลาประมาณ … วัน

แนะนำ: [A/B/C] เพราะ …
ถ้าไม่ทำอะไรเลย: ใบนี้จะค้างต่อและเกิน SLA ในอีก … วัน
```

## ⚠️ ยังต้องถอดวิชาเพิ่มจากคนจริง

**ลำดับการผ่อนเกณฑ์** (ตารางข้างบน) เป็นจุดที่ควรยืนยันกับคนเก่งที่สุด
เพราะเป็นการตัดสินใจที่ต่างกันตามประเภทงาน — งานขับรถกับงานช่างผ่อนคนละแบบ
ควรถามแยกตามกลุ่มงานแล้วเขียนตารางเพิ่มต่อกลุ่ม
